## 计算正确性

- [x] 加减乘除、常数和合法负数正确，计算使用原值而非已四舍五入的展示值。
- [x] 百分比仅改变显示；2,000 ÷ 10,000 的原值为 0.2、展示 20.00%。
- [x] 0、负数、缺失与除零区分，错误行显示“—”及原因。
- [x] 同实验/分组/窗口/共同粒度且唯一键兼容时才可跨能力计算。
- [x] 不按行号、同名维度或自动汇总对齐数据；无契约/重复组合键有明确错误。

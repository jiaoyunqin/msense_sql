## HF-01：状态与日期筛选

筛选栏顺序：关键词 → 报告类型 → 报告状态 → 时间 → 清空筛选。

状态固定为“全部状态 / 分析中 / 已完成 / 部分完成 / 分析失败”。等待、取数和分析阶段映射“分析中”；成功映射“已完成”；中断且有成功结果映射“部分完成”，无成功结果映射“分析失败”。有报告的条目进入报告，未形成报告的任务条目进入任务详情。

时间按钮默认“全部时间”。展开单月日历，月标题居中，两侧切月，星期一为首列，相邻月日期弱化，未来日期禁用，今天有背景标记。底部提供近 7 / 30 / 90 天和清除。当前月的下一月入口禁用。

WHEN 选择开始、结束日期，THEN 以创建时间筛选，包含首尾整日；先选较晚日期时自动排序。第一次点击显示继续选择结束日期的提示，第二次点击生效并关闭面板。

WHEN 点击近 N 天，THEN 包含今天及此前 N−1 个自然日，不按 N×24 小时截断。

WHEN 点击日历“清除”，THEN 仅清除时间；点击“清空筛选”清除关键词、类型、状态及时间，保留我的/全部范围。

WHEN 用方向键浏览日历，THEN 可按天或周移动焦点，Enter 选择，Escape 关闭并返回触发按钮。

## MD-01：多实验报告的模块结构

报告引用模板固定版本，模板按顺序引用已发布多实验分析模块。报告头只承载元信息与数据状态；模块是结论与证据的组织单元。

每个模块按以下固定顺序展示：

1. 模块名称与简短描述。
2. 多实验分析结论卡片，默认可见，带 AI 入口。
3. 卡片底部“分析说明”，展开后展示口径、注意事项及比较边界。
4. 实验名称 / ID 下拉框，靠右排列，窄屏换为独立一行。
5. 当前实验 ID、观察窗口与自身对照组。
6. 单实验分析结论卡片与该实验分析说明。
7. 数据明细、数据集数量及该实验在此模块的数据表。

此结构对应用户第三张截图。截图中黄色文字为说明标注，产品页面采用现有白底、细边框、蓝色操作色。

内置 `r-multi-modules` 为首版演示：核心指标表现与实验策略背景两个模块，3 个独立实验、4 个策略组。第一个模块展示整体与消费力分层两个数据集，第二个模块展示实验配置数据集。

## MD-02：模块、实验与表格状态

WHEN 模块 A 切换实验，THEN 只更新 A 的单实验结论和数据，A 的多实验结论保持固定，模块 B 的选择与数据不变。

实验选择状态保存在模块下；表格状态进一步按实验 ID 与数据集编号隔离。切走再切回可恢复本次页面操作。刷新页面后恢复默认视图，报告快照始终不变。

默认选择首个成功且有模块数据的实验。失败实验保留名称、ID 与不可用标识，选中后说明原因和返回任务入口，不展示旧实验残留数据。

## MD-03：数据与分析范围

只渲染模块已配置、启用展示的来源、指标和粒度。当前已接入独立实验核心指标模拟能力及实验背景配置；其他能力显示未接入原因，不使用其他数据替代。

单实验各策略组分别保留，原始值、相对自身对照组的增幅与逐实验显著性共同展示。分层增幅使用自身同一分层对照组，不继承整体显著性。缺失、无效分母与不适用的指标显示“—”及原因。

WHEN 模块仅配置消费力分层，THEN 多实验结论只能描述已配置分层覆盖与可核对内容，不引用未展示的整体 ROI、成本或整体显著性。

WHEN 模块只配置部分指标，THEN 结论与数据均限于这些指标。背景模块只展示所配置的策略字段，不额外插入核心效果数据。

实验期、观察天数、人群、端或策略不同的比较属于描述性参考。不跨实验合计增量、GMV、补贴或 ROI，不根据排序推断跨实验显著性或因果。

## MD-04：AI 与证据

多实验结论入口引用模块；单实验结论入口引用模块与实验 ID。Agent 初始收起，打开后留在固定侧栏；关闭恢复正文空间。

WHEN 引用 DEMO-002 提问后，将模块切到 DEMO-001，THEN 已保存的问题与回答仍引用 DEMO-002。点击回答证据时切回对应模块的 DEMO-002，再定位结论与数据，不影响其他模块。

回答明确说明本地模拟及证据范围。报告正文不追加问答。旧报告引用保持兼容。

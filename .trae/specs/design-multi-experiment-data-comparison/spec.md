# 多实验数据对比展示 Spec

状态：2026-11-10 按用户最新要求，将两级表头大表格接入全部多实验报告中的多实验分析模块；新生成、内置及历史报告遵循相同规则。验证结果见 `tasks.md` 与 `checklist.md`。

最新范围：多实验报告中的多实验分析模块统一采用“多实验分析结论 → 数据明细大表”。删除实验下拉、单实验分析结论及其 AI 入口/目录项；保留报告级实验核心结论。各指标表按配置顺序直接展开，不提供样式切换、“数据集”选择、模拟说明或底部操作提示。混合报告中的真正单实验模块（例如 Pre AA）继续使用原下拉交互。此规则替代此前“仅独立 Demo 启用、原报告保留下拉”的范围约束。

最新身份口径：实验分析项按“Libra ID × 钱效中心录入实验候选项 ID”去重。同一 ID 的不同候选可同时分析，观察窗口、结果、结论、组列及引用分别保留；重复组合须阻断。详细输入与任务规则以 `docs/spec.md` MA-02/03 为准。

## 为什么

现有数据表适合逐个查看实验内各组，但跨实验比较时需要反复切换并记住数值。直接堆叠多个实验的长表，又会把整体表现、实验组和券批次混在一起，难以找出差异。

全部多实验模块用两级大表格呈现可对齐的整体指标，模块结论位于数据上方。历史报告仅更新阅读展示，沿用当时保存的配置及结果。

## 设计方案

### 1. 根据模块分析类型组织阅读

| 模块类型 | 阅读结构 | 适用范围 |
| --- | --- | --- |
| 多实验分析模块 | 多实验分析结论 → 数据明细大表 | 全部多实验报告，包括新生成和历史报告 |
| 单实验分析模块 | 实验下拉 → 单实验分析结论 → 数据明细 | 混合报告中的 Pre AA 等单实验模块 |

保留“实验属于哪些组”的层级，把同一指标放在一行。批次与分层证据继续保存在原始快照，本期不与整体矩阵混排。

### 2. 页面结构示意

以下为文档线框；报告表头与实验核心结论之后，依次展开各分析模块。

```text
领券核销间隔分布
┌ 多实验分析结论 ─────────────────── AI ┐
│ 当前模块固定的综合结论                 │
└─────────────────────────────────────┘

数据明细

领券核销间隔（整体）
显示范围：3 个实验 · 4 个实验组 ▾     转置  全屏

两级列头：实验名称 / Libra ID → 该实验的组别
指标行：均值、P10、P25、P50、P75、P90
单元格：保存的指标值；可查看对应实验证据
```

混合报告中的单实验模块：

```text
查看单个实验   [完整实验名称 · Libra ID ▾]
观察窗口 / 对照组
单实验分析结论                         AI
数据明细
  PreAA 实验前指标
```

原报告链接及列表条目保留，多实验模块统一为大表格；模块类型取自固定配置，不在页内切换样式。

### 3. 整体矩阵示例

示意值来自当前工程的虚拟数据，仅说明排布。实际界面将同一实验的列合并为一级表头，组别放在二级表头；下表为 Markdown 展平示意。

| 指标（小时） | 周期购券 · DEMO-001策略 A | 周期购券 · DEMO-001策略 B | 关联购券 · DEMO-002策略 A | 唤回券包 · DEMO-003策略 A |
| ------ | ------------------: | ------------------: | ------------------: | ------------------: |
| 均值     |                4.73 |                4.70 |                8.65 |                2.84 |
| P10    |                0.04 |                0.04 |                0.08 |                0.03 |
| P25    |                0.20 |                0.19 |                0.52 |                0.16 |
| P50    |                2.13 |                2.14 |                4.26 |                1.06 |
| P75    |                8.08 |                7.95 |               14.32 |                4.72 |
| P90    |               13.18 |               13.15 |               19.80 |                7.62 |

用户可以沿 P50 一行比较四个组，也能沿某一列查看该组完整分布。DEMO-001 的两个组始终分别保留，不平均成一个“实验结果”。

单位放在指标行名中，保留来源精度。默认不使用红绿底色表达优劣：核销间隔更短不能直接等同于转化或钱效更好。

### 4. 不同数据粒度的呈现

| 数据粒度             | 本期推荐形态       | 对齐规则                            |
| ---------------- | ------------ | ------------------------------- |
| 整体指标、整体分位数       | 跨实验矩阵        | 同一来源版本、同一整体粒度、同一指标语义与单位         |
| 当前模块的整体计算指标      | 满足条件时进入矩阵    | 同一个已保存计算定义及输入口径，不使用名称相同但公式不同的指标 |
| 消费力、城市等分层        | 保留于固定快照 | 本期不做自动跨实验分层对齐；后续可设计“同一维度值对比”    |
| 券批次 ID、商品 ID 等明细 | 保留于固定快照 | 不按行号、名称或局部 ID 拼接不同实验记录          |
| 实验策略等文本配置        | 列头信息 / 固定快照 | 不将长文本强行放进数值矩阵                   |

所有多实验报告中没有整体数据的模块直接说明不可对齐原因，不恢复下拉样式，也不从批次分位数或分层数据合成整体值。

### 5. 阅读密度与操作

* 实验一级表头使用两行名称区域与独立 Libra ID；完整名称通过悬停和键盘聚焦可读。不能让长名称把整张表无限撑宽。

* 指标名称列和两级表头在表格滚动时固定；不同实验列组之间使用细分隔线，不为每个实验堆叠独立卡片。

* 默认展示当前任务实际保存的全部组；原数据有对照行则保留，没有则不补造。例如核销间隔没有未发券对照组数据，矩阵也不新增该列。

* “显示范围”使用可搜索的实验/组别多选下拉，选项按实验归属分组并显示完整名称和 ID。选择仅影响当前数据集的展示，不重新生成结论。

* 实验或组过多时保留全部选项，提供表格横向滚动、全屏和转置，不随机选一个组代表实验。

* 转置后采用“实验 → 实验组”为行、指标为列。只是同一批数据的方向变化，不增加新的报告类型。

* 删除表格上方的固定模拟说明和表格下方的提示区域；来源身份保留在表头、单元格悬停文本和 AI 引用中，不进入单实验下拉样式。

## 新增需求

### 需求 DC-00：全部多实验报告统一展示

#### 场景：打开内置、新生成或历史多实验报告

* **WHEN** 用户打开 `#/report/r-multi-matrix`、`#/report/r-multi-modules`、`#/report/r-mixed-modules` 或工作台生成的多实验报告

* **THEN** 每个多实验模块统一展示多实验分析结论及大表格，一级列头为实验名称与 Libra ID，二级列头为各实验各自的组别。

* **THEN** 多实验模块不展示“跨实验对比 / 单实验明细”切换、实验下拉及单实验分析结论。

* **THEN** 沿用当时的固定结果，各报告独立保存阅读状态和 AI 会话；不修改原报告对象。

#### 场景：历史报告没有矩阵快照

* **WHEN** 已保存的多实验报告只有原始结果和固定模块配置

* **THEN** 阅读阶段投影已保存的整体数值证据，不重新取数或计算，不回写旧快照，不依赖 Demo 标记。

* **THEN** 已有矩阵快照时直接沿用，包括明确保存的空快照；缺少可对齐数据时说明原因。

### 需求 DC-01：在多实验模块中提供整体对比视图

系统应当在全部多实验报告的多实验模块中提供跨实验对比表，并保持模块级多实验结论始终可见。

#### 场景：有整体数据

* **WHEN** 当前多实验模块具有可识别的整体数据集

* **THEN** 综合结论下直接展示矩阵，没有额外样式切换入口。

* **THEN** 不插入逐实验分析结论、实验下拉或独立 AI 入口；原始结果继续保存在固定快照中。

#### 场景：只有分层或明细数据

* **WHEN** 当前模块没有可对齐的整体数据集

* **THEN** 说明“当前模块无可对齐的整体数据”，不自动插入单实验下拉样式。

* **THEN** 不伪造整体数据，不恢复独立的“分析说明”区。

#### 场景：多个整体数据集

* **WHEN** 当前模块有多个不同来源或粒度的整体数据集

* **THEN** 按配置顺序直接展开各张指标表，每张表分别提供显示范围、转置和全屏，不展示“数据集”选择框或计数。

* **THEN** 不仅因指标表标题相同而合并来源；阅读状态按保存的来源身份独立管理。

### 需求 DC-02：保留实验与组别层级，严格对齐指标

系统应当以指标为行，以实验和实验组为两级列头构建矩阵，数据来自当前报告的固定快照。

#### 场景：同一实验有多个策略组

* **WHEN** 一个实验保存了多个组的数据

* **THEN** 每个组分别占列，使用实验 ID、钱效候选项 ID 与组 ID 区分；分析项顺序沿用输入顺序，组别和指标沿用来源顺序。

* **THEN** 不平均或合并这些组，不按名称相似性把不同实验的组认定为等价策略。

#### 场景：指标无法安全对齐

* **WHEN** 来源版本、粒度、单位或计算定义不一致，或者缺少判断依据

* **THEN** 不将这些数据放到同一指标行中比较；保留原始快照并展示对应原因。

* **THEN** 不解析格式化文本反推原始值，不按数组位置配对；本地首版使用明确登记的整体数据集适配，不新增生产接口。

#### 场景：原值、增幅和显著性

* **WHEN** 原始数据集保存了原值及其相对本实验对照组的增幅/显著性

* **THEN** 单元格主行显示原值，辅助行按原口径保留增幅与显著性，并明确“相对本实验对照组”。

* **THEN** 不通过跨实验排序、差值或取平均产生新的显著性；未保存的辅助值不补算。

#### 场景：观察窗口不同

* **WHEN** 被比较实验的观察天数或实验周期不同

* **THEN** 通过列头信息入口展示各实验周期、观察窗口及业务上下文，对比区以简短提示说明观察窗口差异。

* **THEN** 保留原始累计值，不自动折算日均，不把更大的累计值标记为更优实验。

### 需求 DC-03：显示范围、转置和表内证据定位相互独立

系统应当将跨实验对比操作作为阅读状态，不修改取数范围、模板或已生成结论。

#### 场景：缩小显示范围

* **WHEN** 用户在“显示范围”中选择部分实验/组

* **THEN** 只改变当前模块、当前整体数据集的可见列及计数；搜索不清除未显示的已选项。

* **THEN** 显示范围少于两个有效实验时提示“当前仅查看单个实验数据”；仍可查看数值，不生成新的跨实验结论。

* **THEN** 如果用户清空选择，显示空态及“恢复全部”操作，不留下上一组数据。

#### 场景：多组与窄屏

* **WHEN** 列宽超过内容区

* **THEN** 表格横向滚动，不压缩数值字体到难以阅读、不隐藏组别；可切换转置或全屏。

* **THEN** 在窄屏下控件纵向排列，表格方向保持用户选择，不因缩放自动改写视图状态。

#### 场景：定位矩阵单元格的原始证据

* **WHEN** 用户点击或聚焦某个单元格

* **THEN** 保留正确实验、指标表、组别和指标的引用身份，不显示底部操作提示区域，不改变报告样式。

* **THEN** 保持显示范围、数据集及转置状态，不影响其他模块。

#### 场景：AI 引用或目录跳转

* **WHEN** 用户打开指向单实验结论或原数据表的既有引用

* **THEN** 多实验模块的旧单实验结论区域引用转到模块多实验结论，逐实验及数据表引用定位对应大表格证据，必要时恢复被引用的隐藏列。单实验模块仍先选中实验，再定位其结论或数据。

* **THEN** 矩阵单元格引用能识别模块、数据集、实验、组别和指标，阅读状态变化不改变引用目标；保留表格方向和其他已选列。

### 需求 DC-04：部分失败与缺失值必须可识别

#### 场景：报告有失败实验

* **WHEN** 某实验整体取数失败，或者当前模块的数据不可用

* **THEN** 实验仍出现在显示范围列表及对应列头，以不可用状态说明原因；可恢复的组身份按任务快照显示，不编造数值。

* **THEN** 至少两个实验有当前数据集的有效结果时可以对比；不足两个时展示已有数据和不足提示，不把报告级成功数量当作本数据集可比数量。

#### 场景：零值、缺失、不适用

* **WHEN** 数据为零、缺失或该组不适用

* **THEN** 分别保留真实的 0、“— / 未提供”及“— / 不适用”语义，悬停或聚焦可读原因。

* **THEN** 失败、缺失、不可对齐数据不参与任何比较描述，不用其他实验或其他模块的数据代替。

### 需求 DC-06：支持同 ID 的不同钱效中心录入项

#### 场景：同 Libra ID 选择不同候选

* **WHEN** 用户再次解析同一 ID，或点击“添加其他候选项”

* **THEN** 新增独立待选择行，不自动选择候选；日期、删除和后续候选切换只作用于该行。

* **THEN** 同 ID、不同候选可组成多实验输入；同 ID、同候选即使窗口不同也不能重复，已有候选在其他行禁用。

#### 场景：保存结果并展示报告

* **WHEN** 多个分析项使用同一 Libra ID

* **THEN** 输入快照、结果匹配、失败重试及计算上下文包含钱效候选身份，互不借用结果。

* **THEN** 报告头补充钱效实验 ID，单实验模块下拉项、矩阵一级列头和显示范围明确区分候选；二级列头按各候选的实际组别排列。

* **THEN** 阅读状态和 AI 引用按组合隔离；唯一 Libra ID 保留原证据身份并迁移展示引用，重复 ID 缺少结果归属时不猜测。

## 修改需求

### 需求 DC-05：更新多实验模块的阅读顺序

全部多实验报告中的多实验模块固定采用“多实验分析结论 → 数据明细大表”，报告级实验核心结论继续位于报告表头与分析模块之间。

#### 场景：多实验报告包含单实验模块

* **WHEN** 模块固定类型为单实验分析，例如 Pre AA

* **THEN** 不增加跨实验对比入口，保持当前单实验下拉及单实验结论、数据，不升级为跨实验模块。

#### 场景：纯单实验报告与既有样例

* **WHEN** 报告只分析一个实验，或用户查看旧单实验复刻样例

* **THEN** 数据排布、组别切换和表头保持原规则。

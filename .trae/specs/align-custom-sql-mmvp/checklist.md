## 原型验收：编辑与解析

- [x] 空 SQL 时可以展开和搜索参数目录，看到全部可用字段、类型和用法，并在光标处插入占位符。
- [x] 编辑前目录与解析后绑定使用同一份参数定义，未知参数、未绑定参数和类型不兼容阻止试跑或发布。
- [x] 完整 SQL 同时输出指标与维度时，主配置可修改字段角色，并完成绑定、试跑、核对和发布。
- [x] 数字城市 ID 可以声明为维度，SQL 原生数字值不被转换。
- [x] 重解析保留仍有效的人工名称、Key、类型、格式、说明；来源或粒度变化要求复核。
- [x] SQL 或查询配置修改使旧试跑失效；异步旧解析和旧结果不替代当前配置。

## 原型验收：下钻与展示

- [x] 整体、单维、交叉定义都有明确 SQL 变体绑定，只执行已配置变体。
- [x] 多选独立维度分别产出结果，不自动变成交叉查询。
- [x] 交叉成员至少两个、不得重复、来自已声明维度；SQL 输出与成员粒度不匹配时被阻止。
- [x] 下钻名称和 Key 自动生成且唯一，说明选填；Key、说明和 SQL 绑定收在“更多设置”。
- [x] 联合 SQL 实际产出交叉结果；不从独立汇总拼接，不静默求和修复重复粒度。
- [x] 指标展示覆盖整数、小数、百分比、金额、单位、精度与空值，且字段完整性参与发布校验。
- [x] 对照组“—”仅作用于显式配置的比较指标，普通基值仍显示；数据集与快照保留 SQL 原值。
- [x] 修改展示定义要求重新核对，不能复用旧确认直接发布。

## 原型验收：目录与记录

- [x] 目录展示名称、Key、业务目标、说明、来源、当前发布版本、未发布修改提示和更新时间。
- [x] 名称或 Key 搜索、来源、业务目标及全部发布状态筛选可用，包括已归档。
- [x] 内置 SQL 只读查看、试跑和复制；共用入口不允许编辑或复制内置 RPC 为 SQL。
- [x] 来源操作限制在操作处理处校验，不能通过直接入口绕过。
- [x] 归档前展示引用影响并确认；归档后默认隐藏于普通选择，已有固定引用仍有效。
- [x] 能力基础信息校验平台业务目标与负责人邮箱前缀；子 SQL 不重复填写能力组业务信息。
- [x] 首次显式保存后 Key 稳定，改名称不改 Key；手动改 Key 二次确认并展示引用影响，取消保留原值。
- [x] 修改当前 Key 或定义不重写已发布快照，也不自动升级旧分析引用。
- [x] 试跑记录明确属于当前配置对象，不自动进入用户侧报告列表；版本记录有操作、操作人和时间。
- [x] 仅查看或试跑不产生 `vN+1 草稿待发布`，实际定义修改才产生该提示。

## 原型验收：主链路回归

- [x] 四种已有或 SQL 指标维度组合和既有维度交叉来源仍可使用；无明细支持的来源不生成下钻。
- [x] 能力内 SQL 草稿可以随能力整体发布，独立发布不是必需前置；跨组复用继续使用独立发布版本。
- [x] 统一取数验证面板保留范围、上下文、任务、实际 SQL、结果、快照和核对。
- [x] 空数据、失败、权限不足、类型错误、重复粒度、缺少分组或缺少变体不能发布。
- [x] 发布失败不创建假版本，草稿和已有版本保留，可重试。
- [x] 刷新后兼容保留已有草稿、固定版本、引用和记录。
- [x] `npm run build` 通过，浏览器关键链路验证通过。
- [x] 页面保持本地示例执行与本地版本的明确标识，不显示未经实际接入的生产成功状态。

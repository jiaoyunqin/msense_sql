# 分析结论模块展示样式优化（一期规则）

当前前端 Demo 的精简交付规范见 [design.md](../design.md)。本文件保留产品描述及修正记录；字号与颜色关系以该精简规范为准。

2026-11-26 按《对下数据可视化需求》会议中 08:12—09:28 的讨论更新。适用于单实验、多实验报告中的实验核心结论与模块分析结论。阅读者打开报告后，可通过概括句、关键数字和括号说明的层级识别重点；本节替代此前按业务好坏决定颜色、括号内重点数字保留高亮及原样展示小数精度的规则。

## 产品功能描述

| 功能点 | 功能描述 |
| --- | --- |
| 概括句与关键数字 | 关键结论概括句使用深色加粗文字。关键数字统一加粗并略微放大；没有变化方向的关键数字用深色，有明确方向的关键数字按下方规则着色。普通正文与普通数字保持常规字重，不将全部数字或整段证据列表统一加粗。 |
| 提升与下降 | **提升、上升、增加标绿；下降、降低、减少标红**，使用文字颜色，不使用红绿底色。颜色只表达数值变化方向，不代表业务好坏，也不等于统计显著。零变化、未发生的变化、假设或预计的变化，以及无法确定方向的绝对数值不自动着色。 |
| 数字精度与字体 | 结论中的小数和百分比统一四舍五入到两位小数，不足两位补零；例如 `4.4071元 → 4.41元`、`39.8% → 39.80%`、`95% → 95.00%`。整数保持整数，保留千分位、单位及有效正负号；四舍五入后的负零显示为 `0.00`。数字使用专属字体，取整造成数值接近时仍保留原有变化率，不重新计算。 |
| 括号内数据 | 解释性括号及其内容统一使用**浅灰色斜体**。该规则优先于加粗、放大和方向颜色，括号内重点数字也使用浅灰斜体。支持嵌套括号；指标缩写、标识符及数学区间不按补充说明处理。 |
| 结论阅读层级 | 标题、小标题和核心判断使用较深文字及较高字重；普通正文使用较柔和的灰色。结论卡片采用浅蓝渐变背景、细边框和轻阴影，保留段落、列表及标题与正文的层次。标题左侧展示蓝色图表图标，右侧保留 AI 追问入口。 |
| 报告间一致性与原值 | 两类报告共用同一套规则，适用于已有正文与新生成的结论。精度处理仅作用于结论的显示；原始文本、数值、计算结果和引用身份继续保留，格式变化的数字可悬停查看原值。数据明细表沿用其独立精度与展示配置。 |

## 强调判定规则

一期采用可解释的简单规则：根据明确的变化词（如“提升”“减少”“升至”）及数值的显式增减符号识别方向，连续列举的数字沿用该变化方向。成本上升仍标绿、降级率下降仍标红，不因指标的业务含义反转颜色。仅有一个正的绝对值、ROI 高于阈值或置信水平，不据此标绿。

显著性说明按原文保留，不再作为结论区着色的前置条件；例如 `提升+0.23%（不显著）` 中，变化率标绿，“不显著”仍以浅灰斜体展示。缺失或无效结果保留原说明，不补零或编造变化。

优先使用已有概括句或明确的加粗标记；缺少标记时，从正文中选取简短的概括句或引出证据的概括短语。多实验核心指标原本只有逐实验枚举时，以同一份已保存证据补充简短概括句，沿用已有显著性统计，不产生新的跨实验结论。关键数字来自明确的重点标记或当前结论关注指标的选择；具有变化方向或位于加粗概括句中，不自动等于重点。没有固定的每段重点数量限制。

展示优先级为：**括号说明 → 明确变化方向 → 中性关键数字 → 普通内容**。日期、实验 ID、版本号、模型编号和分位数名称不作精度转换。数学区间不加注释斜体，但其中确有小数的边界值仍保留两位。

## 显示标准

| 内容类型 | 当前显示规则 |
| --- | --- |
| 普通正文 | 14px，常规字重，灰色；正文行高 25px。 |
| 普通数字 | 14px，常规字重；使用专属数字字体，保持数字宽度一致。 |
| 关键结论概括句 | 14px，加粗（700），深色；其中的关键数字按对应规则显示。 |
| 中性关键数字 | 15px，加粗（600），深色。 |
| 提升／下降的关键数字 | 15px，加粗（600），分别为绿色／红色；无强调底色。 |
| 提升／下降的一般数字 | 14px，常规字重（400），分别为绿色／红色；不自动加粗放大。 |
| 括号内数字 | 13px，常规字重（400）、浅灰色、斜体，不叠加彩色或放大。 |

数字字体优先使用 Avenir Next；字体不可用时使用同类系统字体替代，保留数字对齐和文字层级。深色主题适配文字与卡片颜色，方向含义保持一致。

## 典型展示场景

| WHEN | THEN |
| --- | --- |
| 结论显示成本由 `4.3763元` 升至 `4.4071元` | 分别显示 `4.38元`、`4.41元`；后者标绿，悬停仍可查看 `4.4071`。 |
| 结论显示降级率下降 `1.04%` | `1.04%` 使用红色文字；选为重点时才加粗放大，不按业务收益改成绿色。 |
| 结论显示 `提升+0.23%（不显著）` | `+0.23%` 标绿；“（不显著）”保留并使用浅灰斜体。 |
| 数字只是背景信息或一般描述 | 使用专属数字字体和常规字重；有明确方向时仅着色，没有方向时保留正文色。 |
| 关键数字没有明确变化方向，例如重点 ROI 为 `1.7` | 显示深色加粗的 `1.70`，字号略大，不自动标绿。 |
| 括号内包含关键数字，例如 `（占比39.8%）` | 显示 `（占比39.80%）`，整段浅灰斜体。 |
| 内容是 `(DAC)`、`DEMO-001`、`2026-10-01`、`v1.2`、`P50` 或 `(5,10]` | 保留内容，不将 ID、日期或编号转换成小数，不额外套用补充说明斜体。 |

## 本轮核对与修正

| 核对项 | 修正前的问题 | 本轮处理 |
| --- | --- | --- |
| 概括句 | 部分模块没有加粗概括句，多实验核心模块只有逐实验数据枚举 | 补齐概括句层级；核心模块概括沿用已有证据。 |
| 重点数字 | 中性重点仍为 14px / 500，没有放大 | 统一为 15px / 600；普通数字保持 14px / 400。 |
| 方向颜色 | 成本上升标红、降级减少标绿；不显著的变化保持中性 | 改为统一按提升／下降着色，保留显著性说明。 |
| 括号 | 重点数字会覆盖灰色斜体；嵌套括号未完整识别 | 统一括号优先，修正嵌套识别。 |
| 精度 | 同时存在四位、一位及整数百分比 | 结论区小数及百分比统一两位，保留原始值用于追溯。 |

已验证：10 项一期规则检查、10 项核心结论检查、35 项矩阵报告检查、15 项混合模块检查和构建通过。浏览器核对两个报告在 1440px、390px 视口及深色主题下的字号、字重、颜色和括号样式；一般涨跌数字为 14px / 400、关键数字为 15px / 600，结论区小数和百分比均归一，页面无横向溢出。单实验报告保留 17 张数据表，多实验报告保留 2 张数据表。

# 分析结论模块展示样式优化

本次优化面向分析报告的阅读场景，通过文字层级、关键数据强调和补充说明样式，让阅读者快速识别核心判断、正负向结果及其解释。适用于单实验与多实验报告中的实验核心结论、模块分析结论；已有结论区域使用一致的展示规则。

## 产品功能描述

| 功能点 | 功能描述 |
| --- | --- |
| 正负向与重点强调 | 对有证据支持的正向关键结果使用**绿色加粗文字**，对负向关键结果使用**红色加粗文字**；对不涉及方向判断的重要数据使用**深灰色适度加粗文字**。仅强调支撑核心判断的关键数据或短语，不将全部数字、整段或整篇结论统一染色、加粗。强调文字不使用红色或绿色底色。 |
| 数字字体 | 结论中的数值采用专属数字字体，使整数、小数、百分比及区间更易识别。同级数字保持一致的显示样式，保留原文的精度、正负号和单位。普通数字使用常规字号、常规字重；中性重点数字仅适度加粗，正负向关键数字在加粗和着色的基础上略微增大字号。 |
| 括号内字体 | 解释、口径、显著性等括号内补充说明采用斜体和较浅的文字颜色，与主结论形成层级区分。括号内的关键数据仍保留自身的强调颜色、字号和字重，不因补充说明样式而弱化。指标英文缩写和数值区间不按解释性括号处理。 |
| 结论阅读层级 | 标题、小标题和核心判断使用较深文字及较高字重；普通正文使用较柔和的灰色。结论卡片采用浅蓝渐变背景、细边框和轻阴影，保留段落、列表及标题与正文的层次。标题左侧展示蓝色图表图标，右侧保留 AI 追问入口。 |
| 报告间一致性 | 相同的文字类型和强调含义在单实验、多实验报告中保持一致。样式优化保留原结论内容、分析口径和引用证据；切换实验或调整数据表的阅读状态不改变整份报告的实验核心结论。 |

## 强调判定规则

颜色由已有分析结论的语义及证据决定，不仅依据数值的正负号判断。成本上升、成本下降或描述性指标变化，需结合指标含义和已确认的结论决定是否属于正向或负向结果；不能直接将上涨等同于收益、下跌等同于损失。

不显著、方向不明确或缺少证据的结果保持中性表达；其中的重要数据可以使用深灰色适度加粗。缺失或无效结果保留原有说明，不通过样式补充效果判断，也不新增业务阈值。

## 显示标准

| 内容类型 | 当前显示规则 |
| --- | --- |
| 普通正文 | 14px，常规字重，灰色；正文行高 25px。 |
| 普通数字 | 14px，常规字重；使用专属数字字体，保持数字宽度一致。 |
| 中性重点数字 | 14px，适度加粗（500），深灰色。 |
| 正向／负向关键数字 | 15px，加粗（600），分别使用绿色／红色；无强调底色。 |
| 补充说明 | 斜体，较浅文字颜色，字号略小于所在正文；其中的重点数据沿用对应强调规则。 |

数字字体优先使用 Avenir Next；字体不可用时使用同类系统字体替代，保留数字对齐和文字层级。深色主题适配文字与卡片颜色，正负向含义保持一致。

## 典型展示场景

| WHEN | THEN |
| --- | --- |
| 结论明确指出某项关键结果正向显著，且对应证据有效 | 对该关键数值使用绿色加粗文字，原有显著性说明继续保留。 |
| 结论明确指出某项关键结果为负向结果，且对应证据有效 | 对该关键数值使用红色加粗文字。 |
| 数字只是背景信息或一般描述 | 使用专属数字字体和常规字重，不自动着色、加粗。 |
| 数字支撑核心判断，但不存在明确的正负向结论 | 使用深灰色适度加粗，字号与普通数字一致。 |
| 关键数值位于解释性括号内 | 括号说明使用斜体，关键数值仍保留对应的强调样式。 |
| 内容是指标缩写或数值区间，例如 DAC、GMV-ROI、(5,10] | 保留指标或区间的原有显示，不额外套用补充说明斜体。 |

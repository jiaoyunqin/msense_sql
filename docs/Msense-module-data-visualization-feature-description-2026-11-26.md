# 实验分析模块 · 数据可视化

## 1. 配置入口

「实验分析模块」→「分析思路」下方的「数据可视化」。区块内提供「AI生成可视化推荐」按钮；「数据条」一行直接展示已选指标标签和「+」。

## 2. 用户操作

- **推荐**：填写分析思路后，点击「AI生成可视化推荐」，从当前已选且用于报告展示的数值取数指标、计算指标中推荐并勾选。无匹配时保留已有选择。
- **添加与删除**：点击「+」，按「取数模块 → 指标」两级勾选，支持按模块整组选择，计算指标单独分组。勾选后立即显示标签，悬停标签并点击右上角「×」即可移除。
- **保存**：选择随模块草稿保存，发布后应用于新生成的报告，已生成报告保留原配置。

## 3. 可视化样式

已选标签和报告明细中的数据条统一使用浅蓝色渐变。报告只给已选指标画条，原值继续显示。同一指标以完整明细中的最高正值为满格，其余正值按比例绘制；零值、负值和缺失值不画条。筛选、排序或转置不改变比例。

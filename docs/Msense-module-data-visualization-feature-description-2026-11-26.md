# 实验分析模块：数据可视化推荐

版本：2026-11-26。依据《对下数据可视化需求》会议关于重点指标推荐和数据条的讨论，以及本轮确认的模块页面与 AI 按钮设计整理。

用户在配置实验分析模块时，根据分析思路选择需要重点比较的指标。报告生成后，仅为这些指标展示数据条，帮助阅读者识别数值大小，减少逐份报告重复配置。

## 产品功能描述

| 功能点 | 功能描述 |
| --- | --- |
| 配置位置 | 在「实验分析模块」编辑页的「分析思路」下方新增「数据可视化」，位于「注意事项」之前。新建和编辑模块使用同一配置方式。 |
| 配置说明 | 显示「基于分析思路 AI 一键推荐重点指标，在报告数据明细中用数据条突出显示。」 |
| 可视化形式 | 本期提供「数据条」。用户展开指标选择区后，可以勾选或取消具体指标；已选指标以标签展示。 |
| 一键推荐 | 点击「AI生成可视化推荐」，参考分析思路与当前已选取数、计算指标，推荐并勾选重点指标。用户可继续手动调整。推荐不新增取数指标，不修改计算公式。 |
| 候选范围 | 仅提供当前已选且会在报告中展示的数值取数指标，以及已配置为报告展示的计算指标。文本、标识符、显著性、检验统计量、置信区间等不参与。SQL 指标须属于当前已选的取数模式。 |
| 默认状态 | 新模块不默认全表展示数据条。尚未选择、推荐无匹配或全部取消时，可以不展示任何数据条；历史报告没有配置时也不自动开启。 |
| 数据条样式 | 采用浅黄色渐变，铺在原值所在行的背景内，数字显示在数据条上方。颜色仅表达数值大小，不代表业务好坏或统计显著性。 |
| 比例口径 | 同一原始指标列的最高有效正值为满格，其余正值按「当前值 ÷ 该列最高正值」绘制。不同指标分别计算，避免将不同单位或量级混入同一尺度。 |
| 版本保存 | 勾选随模块草稿保存，发布后写入模块版本。正式报告读取生成任务固定的模块版本，后续修改草稿或发布新版本不改变已生成报告。模块私有试跑使用本次草稿快照。 |
| 报告应用 | 配置应用于单实验明细、多实验矩阵及模块分析试跑的输入数据。报告页面继续提供筛选、排序、指标拖拽、转置、全屏和 AI 引用，无需重新配置条件格式。 |

## 操作流程与界面文案

1. 选择取数模块及需要展示的指标，按需配置计算指标。
2. 填写「分析思路」。
3. 在「数据可视化」点击「AI生成可视化推荐」，或者直接展开「数据条」手动勾选。
4. 检查已选标签，增删指标后保存草稿；正式使用时发布模块版本。
5. 通过实验分析生成报告，查看所选指标的数据条。

| 元素 | 显示内容 |
| --- | --- |
| 区块标题 | 数据可视化 |
| 说明 | 基于分析思路 AI 一键推荐重点指标，在报告数据明细中用数据条突出显示。 |
| 推荐按钮 | AI生成可视化推荐 |
| 指标选择入口 | 数据条 |
| 选择数量 | 未选择 / 已选 N 项 |
| 推荐成功 | 已推荐并勾选 N 项，可继续调整。 |
| 无明确匹配 | 没有匹配到明确的指标，请手动选择。 |
| 无可用候选 | 请先选择在报告中展示的数值指标。 |
| 未填写思路 | 填写分析思路后可使用推荐，也可以直接勾选指标。 |

未填写分析思路或没有可用候选时，推荐按钮禁用；已有候选仍可手动勾选。修改分析思路不会自动覆盖人工选择；再次点击推荐并匹配成功时，勾选更新为本次推荐结果。没有明确匹配时保留原有勾选。

## 两处 AI 按钮的统一样式

「AI解析生成计算指标」与「AI生成可视化推荐」使用同一种按钮，复用实验报告中已有的 M 形 AI 图标。

| 内容 | 显示标准 |
| --- | --- |
| 图标 | M 形渐变 AI 图标，18 × 18px，位于文案左侧。 |
| 按钮 | 白底、蓝色文字、浅蓝描边，最小高度 28px，圆角 7px。 |
| 文案 | 保留两个入口的完整名称，字号 13px。 |
| 图文间距 | 4px。 |
| 悬停 | 使用浅色背景。 |
| 禁用 | 整体降低透明度，保留图标及文案，不可点击。 |
| 键盘操作 | 聚焦时提供可见轮廓；推荐更新后恢复入口焦点。 |

两个入口承担不同操作：「AI解析生成计算指标」生成可编辑的计算定义；「AI生成可视化推荐」选择报告中需要绘制数据条的已有指标。

## 报告绘制规则

数据条基于完整报告数据缩放。筛选或隐藏实验组后，仍使用原指标完整数据的最高正值；排序、拖拽、转置和全屏不改变比例。

| 原值 | 同列最高正值 | 绘制结果 |
| --- | --- | --- |
| 100 | 100 | 满格，宽度 100%。 |
| 50 | 100 | 宽度 50%。 |
| 25 | 100 | 宽度 25%。 |
| 0 或负值 | 100 | 保留原数字，不绘制数据条。 |
| 缺失、无效或非有限值 | 任意 | 保留原缺失状态及原因，不绘制，不补零。 |
| 全列没有有效正值 | 无 | 整列不绘制数据条。 |

多实验矩阵中，同一个指标在不同实验、策略组之间使用统一尺度；界面转置后仍按原指标计算。原指标与计算指标融合展示时，勾选按「来源 × 指标」身份应用，同名指标不会因名称相同而一起开启。

数据条不改变原值、单位、精度、增幅、显著性或计算来源。原有显著性说明继续显示，不因推荐或条形长度新增、传播显著性。

## 状态与版本场景

| WHEN | THEN |
| --- | --- |
| 打开新模块 | 数据条未选择，不自动给所有指标画条。 |
| 分析思路明确提到可用指标 | 点击推荐后勾选重点项，显示数量和已选标签。 |
| 推荐后手动取消一项 | 取消结果保留；报告不为该项绘制数据条。 |
| 分析思路没有明确匹配或匹配存在歧义 | 保留当前选择，提示手动选择。 |
| 取消取数指标、移除取数模块或关闭指标的报告展示 | 同步移除失效的数据条选择。 |
| 复制模块 | 复制勾选并映射到副本的取数来源，原模块及历史版本不受影响。 |
| 保存后刷新 | 恢复该模块已保存的勾选。 |
| 使用已发布模块生成报告 | 读取任务固定的模块配置；更新模块后，历史报告保持原样。 |
| 同一指标筛选、排序或转置 | 原值、指标身份及缩放尺度保持一致。 |

## 本地 Demo 的实现边界

当前 Demo 尚未接入生产模型、取数或发布服务。「AI生成可视化推荐」通过本地规则匹配分析思路与候选指标，匹配成功时最多推荐三个明确指标；没有匹配时不生成默认推荐。人工选择可以超过三个指标。

「AI解析生成计算指标」支持从分析思路中识别显式二元公式，例如「人均成交金额 = 累计支付 GMV ÷ 进组用户数」。仅使用能明确匹配的已选指标或有限常数，要求输入粒度兼容，生成结果可编辑；不会把一般自然语言自动转成复杂计算。

模块编辑页沿用本轮核对的线上布局，包含基础信息、分析场景、模块观测区间、取数模块、指标与维度排序、计算指标及版本记录。本地业务目标与样例数据的覆盖范围保持现有实现。

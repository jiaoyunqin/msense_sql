# 取数能力目录操作设计

日期：2026-10-22。依据：用户提供的两张截图、当前目录与 `docs/spec.md`。本文记录本轮评估与设计理由，现行行为统一以 `docs/spec.md` 为准。

## 评估结论

初始方案的来源权限合理，可以落地：内置 RPC 只读查看和试跑；内置 SQL 在此基础上支持复制为自定义 SQL；自定义 SQL 支持编辑、试跑和归档。平台定义与用户草稿的边界清楚。

截图中的实际页面还存在四个问题：

1. 空草稿和已发布能力都显示“试跑、配置、用于分析”，无法表达当前真正可做的操作。未发布分析虽然禁用，仍重复占据列表空间；空草稿的试跑点击后才会遇到缺项。
2. “配置”与“展开”没有直接说明编辑和只读查看的差别。同一位置、同类操作应使用“编辑”和“查看”，收起时保持原样。
3. “已选 N 个指标”在 RPC 上表示本次试跑证据，在自定义能力上表示已配置指标，两个数含义不同。目录应说明能力提供或配置的内容。
4. 原要求里的“复制为自定义 SQL”没有明确复制对象。当前目录条目是完整取数能力，SQL 指标、维度子项不是目录条目；目录复制应得到完整的新能力草稿，而不是跳转某一条 SQL。

本轮不重新设计目录容器。保持现有单行卡片、名称、三种来源标签、版本与更新时间、搜索与筛选，在右侧调整操作的名称、次序和出现条件。

## 操作层级与布局

最常用的进入对象操作放在第一位，其后是试跑，再后是已发布能力的分析入口；低频管理操作放在“更多操作”中。

```text
自定义能力：名称  已配置 N 个指标  来源  版本  更新时间    编辑  [试跑]  [用于分析]  …
内置 RPC： 名称  提供 N 个指标    来源  版本  更新时间    查看  试跑
内置 SQL： 名称  已配置 N 个指标  来源  版本  更新时间    查看  [试跑]  …
已归档：   名称  已配置 N 个指标  来源  版本  更新时间    查看  [查看验证]  …
```

方括号表示满足条件才显示。名称点击与首个“编辑／查看”入口保持一致，避免同一行出现不同进入逻辑。所有行内按钮沿用次要样式，目录页头“新建取数能力”保持主操作。

RPC 的“查看”继续就地展开，保留指标、维度及全选。这里的勾选仅选择本次试跑证据，不修改平台能力定义；展开后按钮改为“收起”，选中数在展开内容中展示，标题始终显示“提供 N 个指标”。

## 来源与状态矩阵

| 对象 | 首个操作 | 试跑／历史 | 用于分析 | 更多操作 |
| --- | --- | --- | --- | --- |
| 内置 RPC | 查看 | 未选指标时试跑禁用，选择后可用 | 不新增 | 无 |
| 内置 SQL 完整能力 | 查看 | 配置完整时试跑；不完整但有运行时查看验证 | 不新增 | 复制为自定义 SQL |
| 自定义 SQL，配置不完整且无历史 | 编辑 | 隐藏 | 无发布版本时隐藏 | 归档 |
| 自定义 SQL，配置完整且未发布 | 编辑 | 试跑 | 隐藏 | 归档 |
| 自定义 SQL，已有发布版本 | 编辑 | 完整时试跑；不完整但有历史时查看验证 | 可用，引用最新已发布版本 | 归档 |
| 已归档自定义能力 | 查看 | 有运行时查看验证；不从目录发起新试跑 | 隐藏 | 恢复 |

试跑按钮判断复用现有能力配置检查：名称和说明、实际指标、SQL 解析、输出定义、参数来源绑定与已启用下钻。判断使用定义副本，不为渲染自动修正或保存定义，不执行 SQL，也不要求提前填写实验 ID、观测日期和参数实际值。

正在运行时保留“查看验证”入口，查看当前任务，不重复启动。目录没有发布按钮，试跑、结果核对与发布继续由现有验证浮层承接。

## 每项操作的行为

### 编辑与查看

WHEN 点击可编辑自定义能力的名称或“编辑”，THEN 打开当前能力草稿，可继续修改；已有已发布快照保持。

WHEN 点击内置能力或归档能力的名称或“查看”，THEN 查看现有定义及历史，定义不可编辑。查看不产生保存、试跑或发布记录。

### 试跑与查看验证

WHEN 自定义或完整 SQL 能力通过配置检查，THEN 目录显示“试跑”，进入原取数验证浮层。首次实际取数前沿用原自动保存与 Key 生成规则。

WHEN 当前配置不完整且已有历史，THEN 显示“查看验证”，定位已有运行。历史成功不代表当前草稿通过检查，“获取数据”仍执行原校验。

WHEN RPC 没有勾选任何指标，THEN 禁用“试跑”，悬浮和键盘聚焦均能读取“请先在查看中选择至少一个指标”。勾选后即时启用，不要求重新打开目录。

WHEN 草稿改动使试跑查询失效，THEN 沿用原签名校验要求重新取数；仅展示定义变化要求重新核对。目录不额外维护一套验证状态。

### 用于分析

WHEN 自定义能力未归档且有发布版本，THEN 显示“用于分析”，提示将使用最新已发布 vN，不使用当前草稿。

WHEN 存在未发布修改，THEN 分析入口仍可用，继续引用已发布定义。沿用原切换分析能力的确认与固定版本规则，不以草稿内容覆盖发布快照，不自动升级已有分析。

WHEN 没有发布版本或已经归档，THEN 隐藏入口；处理事件时也检查对象存在、来源、归档与版本状态，不能只依靠按钮显隐。

### 复制为自定义 SQL

这是本轮对原要求的产品解释：目录复制的对象是完整取数能力；能力内部的 SQL 复制仍是原有局部操作，两者不能混用。

WHEN 内置 SQL 能力具备可读取的完整定义，THEN “更多操作”提供“复制为自定义 SQL”；优先复制最新已发布快照，没有发布版本时使用已保存定义。没有完整定义时显示禁用原因，不补造 SQL。

WHEN 点击复制，THEN 生成一份名为“来源名称 · 副本”的自定义能力草稿并打开编辑。保留能力说明、指标及计算表达式、SQL、输出字段与字段 Key、人工设置、参数来源绑定、维度与交叉关系、取值条件和整体展示设置。

能力及所有被复制的 SQL 使用新内部 ID，SQL 归属新能力，重建引用与下钻组。复制出的 SQL 可编辑；字段 Key 作为数据契约保留，能力与 SQL 的稳定 Key 首次保存再生成。试跑上下文采用新建能力的默认值，不把来源实验当作本次任务。

不继承来源试跑结果、核对、发布版本、归档和操作历史。来源能力、来源 SQL 和旧分析保持。定义失效或复制失败时不留下半份能力或孤立 SQL。RPC 不提供此操作；自定义能力继续通过配置页“载入已有取数能力”复用，不新增第二个复制入口。

### 归档与恢复

WHEN 点击“归档”，THEN 沿用影响确认，展示当前分析引用与保留的固定版本。确认后从默认目录移除；取消不改变对象。

WHEN 筛选“已归档”，THEN 可查看定义和验证历史，通过更多操作恢复。恢复后按配置与发布状态重新计算按钮，保留原 Key、SQL、运行与版本，不生成新对象。

归档不删除数据，不改变历史分析的固定输入。平台内置对象不能归档。

## 提示与可访问性

可操作的按钮不附加长篇说明。只有存在阻断或版本含义时提供短提示：“查看当前草稿”“配置未完成，查看历史验证”“使用已发布 vN，不使用当前草稿”。

更多操作点击外部或按 Esc 关闭，打开一个时关闭其他菜单。菜单位置保持在当前行，不能被卡片裁切；Tab 可进入操作，关闭后焦点返回菜单入口。按钮支持键盘焦点样式，禁用 RPC 试跑通过可聚焦提示容器说明原因。

窄屏允许标题元信息和操作自然换行，不压缩名称或把更多操作挤出页面。无操作菜单时不留下省略号占位。

## 可行性与本轮实现边界

配置检查、试跑浮层、版本引用、归档确认已有可复用实现，按钮调整与来源／状态集中判断即可完成。完整 SQL 能力复制需要在已有定义载入机制上增加“所有 SQL 复制为新草稿”，默认载入行为保持。

当前本地种子数据包含自定义完整示例与内置 RPC；内置 SQL 主要作为能力内来源，没有单独的完整目录条目。实现支持具有真实完整定义的内置 SQL 能力，用隔离数据验证该分支，不将 SQL 子项新增为目录能力。

原型只能验证本地交互与数据隔离。正式平台接入后，服务端还需依据真实身份校验来源与操作权限，保存版本及操作记录；本轮不把原型前端规则称为生产权限系统。

本轮按当前工作流更新本地工程、构建并打开本地预览，不推送或部署，不导出离线 HTML 或源码包。

## 实施结果

已实现上述目录操作规则，保留当前工程及原工作区数据。构建与差异格式检查通过。

17 项隔离数据检查通过，覆盖空草稿、已发布／有修改、归档恢复、完整内置 SQL 复制、所有 SQL 独立归属、字段与参数契约、维度引用重建、首次保存 Key、失败原子性及原载入行为。

10 组隔离浏览器交互检查通过，覆盖操作顺序与版本提示、空草稿显隐、菜单 Esc／外部关闭与焦点、RPC 选指标后启用试跑、筛选保留选中与展开、归档恢复、草稿失效后查看历史、只读内置能力复制、副本实际执行四份结果、390px 目录与菜单边界；页面未发现运行异常。额外确认 1600px 桌面下主内容从侧栏右侧开始，无页面横向溢出。

本地 `http://localhost:5173/#/capabilities` 已打开。原浏览器连接在详细检查时连续超时，交互验收改用独立 Chrome 上下文完成，测试数据未写入用户浏览器。完整内置 SQL 能力分支使用隔离测试条目，不改变正式目录种子对象。

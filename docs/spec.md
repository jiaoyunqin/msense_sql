# M-Sense SQL 与取数能力组

维护本文作为当前功能规格。迭代中修改源码并通过 GitHub / Vercel 预览，最后按需统一导出离线文件和源码包。

## 层级

SQL 取数项是可复用的指标或维度定义；取数能力组保存业务目标、指标引用、维度引用与下钻组；分析模块引用能力组的固定发布版本。

主入口是取数能力列表。自定义能力与原有能力放在同一列表，使用相同的能力标题和卡片结构。此前单独放在列表外的两项也是能力组，不是独立 SQL 模块；已有用户数据保持，统一展示。

主路径：已有 / 新建能力 → 填写基础信息 → 在指标 / 维度区域新建 SQL → 自动解析、DS 修正 → 保存并返回能力组 → 整体试跑 → 核对 → 发布能力 → 分析引用并试跑。能力内 SQL 自动关联，不要求 DS 再到外部 SQL 库发布。

SQL 复用库收在可选的“SQL 复用管理”入口，只用于独立验证、发布和跨组复用。配置页显示流程导航，`/#/guide` 提供每一步的实际入口、保存对象和完成条件。

WHEN SQL 独立运行成功并核对发布，THEN 可以将这个版本加入已有能力组，或者新建并保存一个能力组后加入。已有引用显式切换版本，不能重复添加。能力组已有配置和已发布版本保持。

WHEN SQL 尚未独立发布，THEN 可以直接在新能力组或其已归属能力组中保存为能力内草稿，随整个能力组试跑与发布固定完整定义。跨多个能力组复用时先独立发布 SQL 版本。

WHEN SQL 维度加入空能力组，THEN 仍需选择至少一个指标来源，才能执行整体取数和分析。

WHEN 能力组试跑成功且结果已核对，THEN 发布能力组，在分析模块中显式选择此版本并配置分析思路。发布新版本不自动升级旧分析引用。

## 统一试跑面板

WHEN 点击能力目录“试跑”、配置页“整体试跑”或查看结果，THEN 在当前页面之上打开独立的大浮层，复用已有取数验证模块。保留背景配置、实验参数和试跑记录；关闭、返回配置或 Esc 回到原页面，不在能力配置底部拼接整体试跑结果。旧试跑链接打开同一浮层。

指标、维度的独立验证、预置能力和整个能力组试跑共用浮层骨架：标题和当前范围、已选指标 / 下钻维度、实验 ID、观测起止日期、实验信息、取数计划、获取数据、任务状态、结果表、核对及发布入口。未运行时不渲染空结果区；高级上下文参数按需展开。能力编辑只显示最近试跑状态及浮层入口。

WHEN 点击“获取数据”，THEN 由试跑模块校验实验 ID、观测日期、参数绑定、配置与实际结果，并在浮层展示错误、取数状态和表格。失败、空结果或过期运行不可核对发布；修改上下文后不会将旧结果当作当前结果。已知示例实验展示周期，其他实验只展示输入编号，不伪造实验详情。

能力试跑执行已配置的来源与独立 / 交叉下钻，每份结果都有实际 SQL。模板型指标与独立维度来源组合；完整 SQL 仅按自身已声明的输出粒度执行一次，不套用到所有下钻组。独立 SQL 只执行当前取数项；独立维度 SQL 展示实体映射和实际枚举。

## SQL 与组合约束

保留自动解析、DS 名称 / Key / 类型 / 格式 / 精度 / 口径编辑、维度枚举标签与列映射。重解析保留人工设置，异步旧结果丢弃；来源或粒度变化需要复核。人工枚举不转换 SQL 原值。

SQL 编辑器右上角提供“可用参数”，按需展开侧面板；移动窄屏在编辑器下方展开。面板可搜索全部上下文字段，展示名称、Key、类型、含义和占位符，点击插入光标位置。写作前目录与解析后绑定共用定义，未知参数必须绑定到兼容来源。当前为本地示例目录，正式目录由服务端维护。

完整 SQL 可同时自定义指标与维度。解析后可在主表确认角色，数字城市 ID 等可作为维度；根据已确认维度自动登记单维或交叉结果，成员与 SQL 输出同步，保存后随能力整体试跑、发布和分析引用。直接 SQL 已提供聚合维度时，不要求拆成独立实体映射 SQL。

## SQL 配置与指标组（2026-10-22）

参照用户提供的 Libra 截图，页面顺序为 SQL 配置 → 指标组 → 按需展开的 SQL 输出与维度。编辑器只进行语法校验与静态字段解析，不执行查询、不获取样本行、不产生取数记录；权限、空值、真实类型和粒度拦截由试跑模块完成。已关联 SQL 保存后返回能力组整体试跑；独立 SQL 复用验证进入同一个浮层。

SQL 编辑器下方保留“校验并解析 SQL”与模板操作，“上下文入参绑定”放在解析操作下方、指标组上方。完整绑定默认折叠，显示已绑定数量；有未绑定或类型不匹配项时自动展开。同名目录参数自动绑定，未知名称不猜测来源，例如 `${date}` 不自动绑定到观测开始日期。这里仅选择参数来源，实际值在取数验证浮层填写。类型来自静态表达式与已知字段定义，无法确定时交由 DS 确认；枚举仅解析 SQL 显式常量或由 DS 填写，实际取值在试跑结果核对。

指标表只展示指标名、计算类型、表达式与行操作。支持新增、复制、删除和上下移动；Key、口径、格式、精度、单位、空值显示和比较展示收进“更多设置”。“自动配置指标”仅按 SQL 数字输出补齐未配置项，不覆盖现有配置。模板入口提供聚合 SQL、用户粒度指标 SQL 或维度 SQL，应用时替换当前 SQL 与指标配置。

WHEN 解析成功，THEN 将 SQL 实际输出保存到 `draft.fields`，将独立指标定义保存到 `draft.metricDefinitions`。旧配置和已发布快照通过适配继续按 SQL 原值取数，不重写历史定义。同一数字列可以派生多个指标。

WHEN 配置指标计算类型，THEN 支持 SQL 原值、SUM、AVG、UV、A / 进组用户数、A / B 与进组用户数。A / 进组用户数和 A / B 可以选择 SUM、AVG 或 UV 聚合；UV 计算所选数字字段大于零的去重实体数，SQL 必须输出对应实体 ID。聚合按实验组和已声明的维度联合计算，不自动汇总 SQL 原值指标；混合聚合时原值仅在唯一来源行时保留。

WHEN 使用用户粒度模板，THEN 从实验全量示例用户出发，左关联观测窗口订单，保留零订单用户；默认生成 User、订单量、人均订单数、订单渗透和下单用户数。自定义 SQL 的进组人数取决于其实际覆盖的人群，不能把仅有订单的用户当作全量进组人群。

WHEN 重新解析或 SQL 暂时解析失败，THEN 保留人工指标配置。已删除指标不会被重解析恢复；引用字段消失时显示失效字段并阻止试跑、发布，DS 修正后再继续。指标名称、格式与精度改变后可复用当前原始结果，但核对表立即应用新定义并要求重新核对；计算表达式或来源改变后需要重新取数。指标定义随能力关联、保存配置、固定发布版本与分析输入完整传递。

保留四种已有 / SQL 指标维度组合和三种维度交叉来源。模板组合保留明确的 SQL 位置，交叉实际关联明细并联合分组，禁止从独立汇总推导。完整查询仅提供自身的实际粒度，增加其他下钻需另行提供相应 SQL 或模板。

组合名称和 Key 自动生成；Key 只读，在能力保存后收在“更多设置”，与选填说明和“查看绑定 SQL”一起展示。成员、唯一性和实际粒度必须校验，说明不新增发布阻断。字段的单位、空值和比较展示收在“更多”；对照组比较指标可以显示“—”，普通基值保持展示，原始 SQL 值不变。

## 维度选择与交叉（2026-10-22）

能力配置将“下钻维度”和“下钻分组”合并为“维度”。参照 Libra 的就地选择器、浅底维度卡、堆叠交叉卡和整体数据开关；不另设一张重复配置表。参考链接为 Libra 实验 4823214 的 adhoc 页面，本次页面需要登录，交互依据用户提供的六张截图。

维度选择器支持搜索，按“指标内置 / 公共维度 / 自定义 SQL”分栏。指标内置只列出已选指标组自带的维度；公共维度由平台维护；自定义 SQL 包括可复用的已发布维度、当前能力内维度，以及指标 SQL 自带的实际输出粒度。当前内置 SQL 指标组提供消费力分布，公共目录提供生命周期和城市 ID。原目录 RPC 仍保持固定样例边界，不凭空为未接入的 RPC 生成 SQL。

WHEN 多选普通维度并添加，THEN 每项生成一张独立卡和独立 SQL 变体，彼此不隐式交叉。重复添加同一个独立维度不可产生重复任务。

WHEN 点击“交叉维度”，THEN 在一个卡片中显式选择 2–4 个不同成员，可跨来源选择；保留已有独立卡，交叉单独执行。每个成员支持移除，成员不足两个时阻止试跑与发布。交叉名称自动由成员生成。

WHEN 维度有已知枚举值，THEN 卡片“拆解”默认全部取值，可选择部分值；条件作用于对应变体的 SQL 输出，不改变整体查询。字符串、数字、NULL 保持原生值与类型；空选择、失效字段或类型不匹配必须校验。

WHEN 完整 SQL 已输出单维或交叉粒度，THEN 作为一张绑定 SQL 的维度卡，可选择是否启用；交叉成员不可拆开冒充独立结果。添加其他粒度须有对应 SQL 或支持下钻的指标模板，缺少执行能力时在选择器及校验中给出原因，禁止静默跳过。

WHEN 切换“展示不拆分维度的数据”，THEN 只改变结果展示与新分析的默认输入，不修改查询签名、不重新取数。整体数据来自实际整体 SQL，不从分层结果汇总推导。仅有带维度的完整 SQL 时开关不可用；没有任何可展示的拆分时不能隐藏唯一整体结果。

WHEN 保存配置、刷新或发布能力，THEN 保留维度来源、独立/交叉成员、启用状态、取值条件和整体展示设置；配置复制重建对象引用，固定发布版本和已有分析不变。展示定义修改后复用原始数据，但核对表必须应用当前定义后才能重新确认。

维度卡的“更多设置”保留每个成员的引用版本、查看/复制 SQL 与草稿编辑入口，交叉成员也可逐一管理。复制维度 SQL 替换当前引用时，已有拆解条件迁移到新维度 Key。指标内置维度必须保留其所属指标组，失去所属组后提示修正，不再作为公共维度继续执行。选择器支持 Esc 或点击外部关闭；没有实际整体 SQL 时开关显示关闭且不可用。

SQL 或查询配置变化使当前取数失效，展示定义变化要求重新核对。空数据、权限不足、错误、错类型、实体重复或关联缺失不能发布。

## 简洁的管理入口

能力目录沿用原卡片，补来源与状态筛选、名称 / Key 搜索、更新时间和 `vN+1 草稿待发布`。来源标签：内置 RPC 蓝、内置 SQL 绿、自定义 SQL 紫。仅查看、试跑或解析注释元信息不产生定义修改提示。

SQL 复用库同样支持名称 / Key、来源及状态筛选，内置 SQL 可只读查看、试跑和复制；内置 RPC 不开放 SQL 编辑或复制。自定义对象的归档收进卡片“更多操作”，确认引用影响后归档；归档对象不用于新增选择，可恢复，已有固定版本引用保持。

能力和 SQL 取数项的稳定 Key 是系统标识。创建时仅分配内部 ID，Key 留空且不展示。首次保存草稿、保存并返回能力组、保存关联时自动分配唯一 Key，之后只读展示；没有填写或修改入口，改名、再次保存及新版本发布均不改 Key。首次试跑前如未保存，系统先保存草稿再执行，固定的运行快照已含 Key。创建和校验不会要求 DS 填写 Key；已有已保存 Key 与历史发布快照保持。

能力基础信息只保留名称、固定业务目标“平台老客提频”和说明。删除负责人字段及对应校验；关联窗口的新建能力组也使用相同规则。目录与分析模块业务目标同样只读展示“平台老客提频”。系统操作记录中的操作人来自执行身份，与已删除的负责人表单无关。

以上以用户 2026-10-22 的最新调整为准，替代原交付文档中“Key 可修改”“负责人必填”及多业务目标的表单规则。SQL 输出字段的 Key 属于数据契约，仍由解析填充并允许 DS 按已有流程修正。试跑记录仅属于当前配置对象，新发布记录保存操作、操作人和时间；历史未记录的操作人不补造。

## 轻量取数配置复用

入口统一为“保存取数配置”和“载入已有取数配置”。能力新建 / 编辑、独立 SQL 新建 / 编辑、所有取数试跑页均可使用；原目录内置 RPC 的指标选择区也有入口。能力目录可直接载入。使用一个配置列表，不区分公共配置与我的配置。

WHEN 点击保存取数配置，THEN 只需填写配置名称，可选填说明；保存当前指标、维度、下钻组、实际 SQL 与字段定义、参数绑定及实验和观测时间。允许保存未完成或尚未试跑的配置；每次保存新增一份，不覆盖同名配置、能力版本或其他配置。列表展示来源类型、范围摘要和保存时间，支持名称 / 说明搜索与删除。

WHEN 载入能力或 SQL 配置，THEN 以保存时的快照新建独立草稿，允许继续修改并另存；自定义 SQL 一并复制，内置来源保留确定版本引用。新对象使用新的内部 ID，稳定 Key 在首次保存时生成；不携带试跑结果、核对状态、版本、归档状态或操作历史。SQL 输出字段 Key 与人工修正保持。来源后续修改或归档不改变配置快照。载入独立 SQL 后，可通过已有“关联 / 新建能力组”操作组合。

WHEN 载入预置能力配置，THEN 恢复对应能力的指标、独立下钻维度和试跑上下文，并打开同一取数验证浮层。用户可返回指标选择区调整，再保存另一份配置。修改上下文或载入配置后清除当前示例结果。原目录 RPC 仍只展示固定样例数据；结果区简要标明“固定样例，结果不随实验与日期变化”。

WHEN 列表为空或搜索无结果，THEN 提示如何保存或调整搜索。删除需在弹窗中确认，且只删除配置条目，已经载入的草稿与原能力保持。配置与工作区一样保存在当前浏览器，刷新可继续使用。

## 页面文案

配置与试跑页面只保留操作、字段含义、结果状态及必要约束。删除 SQL 示例与输出约定区、示例填充按钮、首页体验横幅、底表字段清单、部署说明，以及反复出现的原型/本地执行备注。参数目录继续保留名称、类型和用法，试跑结果保留“查看执行 SQL”。

## 运行与部署边界

Vite、原生 JavaScript、Lucide、sql.js。浏览器 Worker 执行生成的示例底表，存储键 `msense-composer-v2`。GitHub 保存源码，Vercel 部署可交互原型；生产 SQL 服务、权限、版本注册和模型服务尚未接入。

内置“优惠券支付分析 · 完整示例”：固定 ID `demo-sql-ability`，含 SQL 支付指标、SQL 消费分层和已有生命周期。真实示例 SQL 预先完成解析、独立运行、发布 v1、能力整体 / 两个单维 / 交叉运行、发布 v1 与分析。结果不是随机拼装；支付 GMV 对照组 7098、实验组 8286；结果行数 2 / 6 / 4 / 12。样例存于 `src/composer-demo.json`，初始化只补充缺少的示例，不重置用户草稿或分析引用。

SQLite 使用内联 WebAssembly 二进制，减少对浏览器 JavaScript 栈大小的依赖。旧离线 HTML 未自动更新，用户通过线上地址体验当前改动；最终需要时再导出。

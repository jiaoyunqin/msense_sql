# M-Sense SQL 与取数能力组

维护本文作为当前功能规格。迭代默认只修改与验证本地工程，并为用户打开本地预览；只有用户明确要求时才推送 GitHub 或更新 Vercel。最后按需统一导出离线文件和源码包。

## 层级

SQL 取数项是可复用的指标或维度定义；取数能力组保存业务目标、指标引用、维度引用与下钻组；分析模块引用能力组的固定发布版本。

主入口是取数能力列表。自定义能力与原有能力放在同一列表，使用相同的能力标题和卡片结构。此前单独放在列表外的两项也是能力组，不是独立 SQL 模块；已有用户数据保持，统一展示。

目录页「新建取数能力」按钮与能力数量标签同高 36px、圆角 8px、间距 12px，垂直居中对齐。数量标签采用灰色弱化展示；窄屏下标题独占一行，按钮与数量标签在下一行保持对齐。

用户新建的一次完整取数配置就是一个独立取数模块，对应一个能力组和一个目录条目，可以跨多个已有可用来源配置指标、维度与 SQL。SQL 子项和保存的配置快照不自动成为目录模块。

主路径：已有 / 新建能力 → 填写基础信息 → 在指标 / 维度区域新建 SQL → 自动解析、DS 修正 → 保存并返回能力组 → 整体试跑 → 核对 → 发布能力 → 分析引用并试跑。能力内 SQL 自动关联，不要求 DS 再到外部 SQL 库发布。

复用统一在可编辑能力配置页载入已有完整取数能力，当前能力内继续支持选择已有指标、编辑／复制 SQL 和配置维度。SQL 子项不要求通过独立管理页创建或发布才能完成能力配置。`/#/guide` 提供每一步的实际入口、保存对象和完成条件；配置页不展示流程导航栏。

WHEN SQL 独立运行成功并核对发布，THEN 可以将这个版本加入已有能力组，或者新建并保存一个能力组后加入。已有引用显式切换版本，不能重复添加。能力组已有配置和已发布版本保持。

WHEN SQL 尚未独立发布，THEN 可以直接在新能力组或其已归属能力组中保存为能力内草稿，随整个能力组试跑与发布固定完整定义。未发布 SQL 只能归属一个能力组；载入其他能力时复制为目标能力内草稿，不要求先独立发布 SQL 版本。

WHEN SQL 维度加入空能力组，THEN 仍需选择至少一个指标来源，才能执行整体取数和分析。

WHEN 能力组试跑成功且结果已核对，THEN 发布能力组，在分析模块中显式选择此版本并配置分析思路。发布新版本不自动升级旧分析引用。

## 统一试跑面板

WHEN 点击能力目录“试跑”、配置页“整体试跑”或查看结果，THEN 在当前页面之上打开独立的大浮层，复用已有取数验证模块。保留背景配置、实验参数和试跑记录；关闭、返回配置或 Esc 回到原页面，不在能力配置底部拼接整体试跑结果。旧试跑链接打开同一浮层。

指标、维度的独立验证、预置能力和整个能力组试跑共用浮层骨架：标题和当前范围、已选指标 / 下钻维度、实验 ID、观测起止日期、实验信息、取数计划、获取数据、任务状态、结果表、核对及发布入口。未运行时不渲染空结果区；高级上下文参数按需展开。能力编辑有实际记录后只显示紧凑验证摘要及浮层入口，无记录不显示验证空卡片。

WHEN 点击“获取数据”，THEN 由试跑模块校验实验 ID、观测日期、参数绑定、配置与实际结果，并在浮层展示错误、取数状态和表格。失败、空结果或过期运行不可核对发布；修改上下文后不会将旧结果当作当前结果。已知示例实验展示周期，其他实验只展示输入编号，不伪造实验详情。

### 试跑输入、结果与历史（2026-10-22）

WHEN 从目录“试跑”或配置页“整体试跑／进入取数验证”打开浮层，THEN 默认显示已选证据、展开的实验 ID 与观测时间、更多入参和取数计划，沿用当前默认或已填写参数。即使已有历史运行，也不自动展示任务完成、结果或发布入口，不执行取数、不新增记录。明确“查看结果／查看验证”的入口继续可定位对应结果；目录查看验证进入该轮只读记录。

WHEN 点击“获取数据”且实际创建新运行，THEN 浮层只展示该轮的任务、运行状态、失败信息和结果，完成后沿用核对及发布。校验未通过且未创建运行时仅显示输入错误，不显示旧成功。修改实验、日期或其他入参后回到输入态并隐藏旧任务／结果，重新取数才显示新结果；重复点击运行中按钮不会创建重复任务。关闭后重新点击“试跑”仍默认输入态，当前参数及既有记录保留。

浮层标题区仅对创建人且已有记录时提供“历史试跑记录（N）”；目录更多操作使用相同条件。完整能力配置页在验证摘要之后、发布记录之前增加默认收起的“试跑记录 · N 次”，非创建人或无运行不渲染空区块；首次出现、切换能力及重载默认收起，同能力保存、状态更新、查看返回保留展开与滚动。历史读取当前对象 `runs`，一轮整体取数计一次，不以子任务或实验数计数，最近在前，展示当次实验 ID、开始时间、真实执行状态和查看入口；缺失值准确标明，不补造。

WHEN 点击历史记录，THEN 同一浮层展示该轮保存的上下文、定义、字段、任务、结果、SQL 与错误，明确为“试跑记录”。入参只读，隐藏获取数据、核对及发布。按运行 ID 严格定位，缺失记录报错，不静默回退到其他运行；缺少定义时仅展示已保存部分并标明。当前指标名、格式、分组或实验修改不会改写历史快照。

WHEN 点击“返回当前验证”，THEN 恢复进入历史前的输入与结果视图，不载入历史参数、不取数、不恢复核对；当前配置不满足试跑条件时保留返回配置。记录查看、切换任务、开关浮层及折叠不会增加次数、改变定义／上下文／核对／发布／分析引用，也不进入用户侧报告列表。运行中查看历史仍固定所选轮次，实际任务继续更新原运行。

独立 SQL 的试跑浮层同样默认输入态并查看自己的历史。能力内 SQL 记录不混入能力整体记录；载入保留目标历史、不继承来源历史，新副本没有来源历史。RPC 仍为固定样例：点击获取数据后才展示样例，重开回到输入态，不为未接入的 RPC 补造持久化任务或历史。

能力试跑执行已配置的来源与独立 / 交叉下钻，每份结果都有实际 SQL。模板型指标与独立维度来源组合；完整 SQL 仅按自身已声明的输出粒度执行一次，不套用到所有下钻组。独立 SQL 只执行当前取数项；独立维度 SQL 展示实体映射和实际枚举。

WHEN 能力或独立 SQL 没有试跑记录且配置未完成，THEN 保留基础信息、指标、可选维度及保存操作，仅可编辑能力页另提供“载入已有取数能力”，隐藏试跑和发布入口；页头操作附近只显示现有配置检查的首个待补项，不在输入期间自动展开红色错误清单。保存或生成 Key、解析 SQL、打开或关闭浮层均不产生试跑或发布记录。

WHEN 配置通过现有静态检查，THEN 能力页头出现“整体试跑”，独立 SQL 出现“进入取数验证”。检查名称和说明、至少一个实际指标、SQL 解析、输出定义、参数来源绑定及已启用下钻的完整性；不执行 SQL，不要求先保存或生成 Key，也不要求先填写实验 ID、观测日期及参数实际值。实际入参和取数结果仍在浮层获取数据时校验；首次试跑沿用自动保存规则。维度可选，仅整体配置可试跑；完整 SQL 的单维／交叉输出仍按自身实际粒度使用。

WHEN 创建人查看能力且 `runs` 非空，THEN 配置内容之后显示一行“取数验证 · 实际状态 · 对应记录时间”，提供“查看结果”，详细结果、历史、执行 SQL 和核对仍在同一浮层；非创建人或没有记录时不渲染标题、边框、空正文或预留高度。运行中、成功待核对、已核对、空结果、失败、权限不足和超时均能查看。独立 SQL 继续使用原页头和浮层，不新增配置页结果摘要。

摘要优先当前查询有效的运行，否则取最近实际运行；正在运行的新记录优先显示运行中。沿用最新同查询签名记录决定当前运行的规则，同签名失败不能回退到更早成功。状态和时间来自同一条记录，不以历史成功代替当前验证。查询或上下文变化显示“需重新试跑”；仅展示定义变化且已有核对签名非空但失配时显示“需重新核对”，保留原始数据并在浮层应用最新定义。首次成功未核对或撤销核对显示“成功待核对”。

WHEN 当前有效结果核对签名匹配、正常场景与完整结果满足已有发布检查且对象允许发布，THEN 页头和浮层出现原发布按钮，保留发布确认和执行门禁；未核对、撤销核对、查询失效、展示需复核或只读时隐藏。直接路由、目录入口、旧试跑链接继续执行原检查，不以显隐代替校验。

WHEN 创建人查看能力或 SQL 且 `versions` 非空，THEN 在验证摘要之后显示默认收起的“发布记录 · 实际版本数量 · 最新版本号及发布时间”，展开沿用原倒序版本明细、操作、操作人、查看快照及分析／关联操作。非创建人或没有版本时不渲染历史区块；缺失时间或操作人沿用缺失值展示，不补造。首次发布成功才新增记录，失败不增加版本或改变已有内容。

发布记录首次出现、切换对象及浏览器重载时默认收起；同一对象编辑、保存、核对或局部更新保留本次展开状态，折叠只控制显示、不触发业务操作、不写入定义。草稿修改不隐藏创建人的历史版本，不改变固定快照和分析引用。

配置输入、指标／维度调整、SQL 解析、核对切换、运行结束、发布成功／失败和关闭浮层后即时更新入口及摘要，无需手动刷新，不重建正在编辑的表单而丢失输入、光标或滚动位置。折叠标题支持键盘及明确展开状态；入口出现不抢焦点，发布入口退出或关闭浮层后原入口消失时，焦点移到邻近可用操作或合理页头操作。沿用现有配色、字号、边框、圆角与按钮，窄屏自然换行。

展示状态复用配置检查、当前运行、查询／核对签名和发布检查，不另存业务流程状态，不主动改变定义。本轮与目录标签／筛选变更独立，继续维护现有工程，不新增离线 HTML 或源码压缩包。

### 归属与读取契约

当前模块以完整能力的稳定内部 ID 为归属，不按名称、实验 ID 或发布版本分组。只读取该能力实际的 `runs`；同一实验执行两轮算两次，每轮整体、独立维度及交叉任务均为子任务，不增加标题次数。保持保存顺序，最近运行在前，同一时间也不排序或去重。保存草稿、解析 SQL、打开或关闭浮层、查看、切换结果及核对均不增加记录；只有现有执行流程实际创建运行才计数，入参校验失败且尚未创建运行时不计数。

WHEN 用户切换到另一能力、载入已有能力或复制新能力，THEN 只显示目标自己的记录。载入保留目标历史且不继承来源历史，复制的新能力没有来源运行、核对或发布记录；改名、编辑或发布后原历史仍归属于原能力。

入口用于有实际运行的完整能力，包括可读取的内置 SQL，仅创建人可查看历史。独立 SQL 和分析模块继续保留自己的记录，本次不新增 SQL 编辑页记录区，不合并能力内 SQL 子项或分析运行。预置 RPC 的固定示例及“查看示例”次数不补造为历史任务。

共享纯读取 API 位于 `src/composer-trial-records.js`，不读取全局模块、当前验证或报告集合，不修改输入：

| API | 返回契约 |
| --- | --- |
| `trialRuns(obj)` | `obj.runs` 为数组时返回原数组，否则返回 `[]`；次数使用数组长度，顺序和对象身份保持。 |
| `findTrialRun(obj, runId)` | 只按当前对象内严格相等的 `id` 返回原记录；缺失或空 ID、记录不存在均返回 `null`，不回退至最近运行、当前验证或其他模块。 |
| `trialRecordStatus(run)` | 只映射当次 `status`：`running` 为“运行中”、`success` 为“已完成”、`empty` 为“空结果”、`failed` 为“失败”、`permission` 为“权限不足”、`timeout` 为“超时”、`insufficient` 为“分析输入不足”；其他或缺失为“状态未记录”。 |
| `trialRecordTime(run)` | 仅格式化有效的 `startedAt` 为 `zh-CN` 可读日期及 24 小时时分秒；缺失或无效为“时间未记录”，不读取当前时间、完成时间或模块更新时间补齐。 |
| `trialExperiment(run)` | 仅将已保存的 `run.context.libra_id` 转为字符串，缺失返回空字符串；不使用运行 ID 或当前实验补齐。 |

所有读取不补造旧记录的定义、上下文、字段或结果，不修改查询／核对签名、当前草稿、发布快照、操作历史或分析引用。返回原数组及原记录用于精确定位，调用方不得因展示排序、写入或补齐它们。

### 渐进展示

WHEN 当前完整能力没有实际记录，THEN 不渲染“试跑记录”的标题、边框、说明、空态或预留高度，仅打开浮层不能生成空区块。首次实际创建记录后，即使运行中或失败，也在取数验证摘要之后、发布记录之前显示默认收起的“试跑记录 · N 次”；无发布版本时仍独立显示。

首次出现、切换模块及浏览器重载默认收起；同一模块编辑、保存、核对、状态更新和关闭详情后保持本次展开及合理的列表滚动。折叠状态仅属于当前界面，不持久化到定义或形成草稿差异。实际运行开始、结束或失败后即时更新数量和状态，不重建配置输入、不丢失光标、内容或页面滚动，新记录插入顶部但不主动展开或抢焦点。

展开后说明模块归属一次，每行提供“实验 X”（缺失为“实验未记录”）、当次开始时间、实际执行状态及使用唯一运行 ID 的“查看”入口；入口有文字或可访问名称，不只展示无说明的箭头。沿用已有字号、边框、圆角、按钮及蓝色试跑图标；标题支持键盘并暴露展开状态，长列表局部滚动且记录全部可达，桌面约可容纳三行，窄屏自然换行，时间保持可读。

“已完成”只表示这轮取数成功，不证明当前草稿已核对或可发布。WHEN 当前查询、下钻或上下文改变，THEN 旧行保留原状态和时间，当前摘要仍按原规则提示“需重新试跑”；仅展示定义变化时仍按原规则要求重新核对。同签名最新运行失败不能回退到更早成功以开放核对或发布。

## SQL 配置与指标组（2026-10-22）

按用户最新纠正，自定义 SQL 表单的顶层只有“指标”和“维度”两个大区块。指标 SQL 配置器、上下文入参绑定、字段设置、解析操作和指标表均位于指标区内；自定义维度的 SQL 配置器、实体映射、参数绑定、解析操作和维度表均位于维度区内。SQL 配置不再独立为顶层栏目，维度 SQL 不再使用单独浮层。指标字段与角色总表仍位于指标 SQL 配置内的“SQL 输出字段”。编辑器只进行语法校验与静态字段解析，不执行查询、不获取样本行、不产生取数记录；权限、空值、真实类型和粒度拦截由试跑模块完成。已关联 SQL 保存后返回能力组整体试跑；现有独立 SQL 验证进入同一个浮层。

SQL 编辑器下方保留“校验并解析 SQL”与模板操作，“上下文入参绑定”放在解析操作下方、指标组上方。完整绑定默认折叠，显示已绑定数量；有未绑定或类型不匹配项时自动展开。同名目录参数自动绑定，未知名称不猜测来源，例如 `${date}` 不自动绑定到观测开始日期。这里仅选择参数来源，实际值在取数验证浮层填写。类型来自静态表达式与已知字段定义，无法确定时交由 DS 确认；枚举仅解析 SQL 显式常量或由 DS 填写，实际取值在试跑结果核对。

指标表只展示指标名、计算类型、表达式与行操作。支持新增、复制、删除和上下移动；Key、口径、格式、精度、单位、空值显示和比较展示收进“更多设置”。“一键解析配置指标”先解析当前 SQL，再补齐未配置的数字指标，保留现有名称、表达式与人工设置。模板入口提供聚合 SQL、用户粒度指标 SQL 或维度 SQL，应用时替换当前 SQL 与指标配置。

维度大区块保留“指标内置／公共维度／自定义 SQL”三类来源，支持选择、新建独立 SQL、拆解条件、整体展示与显式交叉。点击自定义来源中的“新建 SQL 维度”或已有能力内维度的“编辑 SQL”，在此大区块内展开自己的 SQL 配置器和维度表，解析入口位于该编辑区内；“保存维度”应用配置，“取消编辑”丢弃临时改动。区块也展示当前指标 SQL 自带的维度，可修正名称、类型或将其他实际输出设为维度；Key 与口径沿用“更多”设置。未关联能力的独立 SQL 仍展示指标和维度两大块，关联能力后可使用三类下钻来源。

WHEN 点击区块内一键解析，THEN 处理当前 SQL 并刷新对应配置与能力引用；旧异步结果不覆盖新 SQL，解析失败保留最近成功字段与人工配置，不新增运行或发布记录。维度解析不凭空从完整 SQL 生成其他粒度；数字字段的维度角色仍由已知定义或 DS 修正决定。当前原型使用已有静态解析器承接一键配置，尚未接入模型服务。

WHEN 解析成功，THEN 将 SQL 实际输出保存到 `draft.fields`，将独立指标定义保存到 `draft.metricDefinitions`。旧配置和已发布快照通过适配继续按 SQL 原值取数，不重写历史定义。同一数字列可以派生多个指标。

WHEN 配置指标计算类型，THEN 支持 SQL 原值、SUM、AVG、UV、A / 进组用户数、A / B 与进组用户数。A / 进组用户数和 A / B 可以选择 SUM、AVG 或 UV 聚合；UV 计算所选数字字段大于零的去重实体数，SQL 必须输出对应实体 ID。聚合按实验组和已声明的维度联合计算，不自动汇总 SQL 原值指标；混合聚合时原值仅在唯一来源行时保留。

WHEN 使用用户粒度模板，THEN 从实验全量示例用户出发，左关联观测窗口订单，保留零订单用户；默认生成 User、订单量、人均订单数、订单渗透和下单用户数。自定义 SQL 的进组人数取决于其实际覆盖的人群，不能把仅有订单的用户当作全量进组人群。

WHEN 重新解析或 SQL 暂时解析失败，THEN 保留人工指标配置。已删除指标不会被重解析恢复；引用字段消失时显示失效字段并阻止试跑、发布，DS 修正后再继续。指标名称、格式与精度改变后可复用当前原始结果，但核对表立即应用新定义并要求重新核对；计算表达式或来源改变后需要重新取数。指标定义随能力关联、保存草稿、载入已有能力、固定发布版本与分析输入完整传递。

保留四种已有 / SQL 指标维度组合和三种维度交叉来源。模板组合保留明确的 SQL 位置，交叉实际关联明细并联合分组，禁止从独立汇总推导。完整查询仅提供自身的实际粒度，增加其他下钻需另行提供相应 SQL 或模板。

组合名称和 Key 自动生成；Key 只读，在能力保存后收在“更多设置”，与选填说明和“查看绑定 SQL”一起展示。成员、唯一性和实际粒度必须校验，说明不新增发布阻断。字段的单位、空值和比较展示收在“更多”；对照组比较指标可以显示“—”，普通基值保持展示，原始 SQL 值不变。

## 维度选择与交叉（2026-10-22）

能力配置将“下钻维度”和“下钻分组”合并为“维度”。参照 Libra 的就地选择器、浅底维度卡、堆叠交叉卡和整体数据开关；不另设一张重复配置表。前一轮交互依据用户截图；本轮已成功访问 Libra 实验 4823214 的 adhoc 页面，并核对“SQL自定义维度”弹窗。

维度选择器支持搜索，按“指标内置 / 公共维度 / 自定义 SQL”分栏。指标内置只列出已选指标组自带的维度；公共维度由平台维护；自定义 SQL 包括可复用的已发布维度、当前能力内维度，以及指标 SQL 自带的实际输出粒度。当前内置 SQL 指标组提供消费力分布，公共目录提供生命周期和城市 ID。原目录 RPC 仍保持固定样例边界，不凭空为未接入的 RPC 生成 SQL。

WHEN 多选普通维度并添加，THEN 每项生成一张独立卡和独立 SQL 变体，彼此不隐式交叉。重复添加同一个独立维度不可产生重复任务。

WHEN 点击“交叉维度”，THEN 在一个卡片中显式选择 2–3 个不同成员，可新增多组、跨来源选择；保留已有独立卡，各组交叉单独执行。每个成员支持移除，成员不足两个或超过三个时阻止试跑与发布。交叉名称自动由成员生成。

WHEN 维度有已知枚举值，THEN 卡片“拆解”默认全部取值，可选择部分值；条件作用于对应变体的 SQL 输出，不改变整体查询。字符串、数字、NULL 保持原生值与类型；空选择、失效字段或类型不匹配必须校验。

WHEN 完整 SQL 已输出单维或交叉粒度，THEN 作为一张绑定 SQL 的维度卡，可选择是否启用；交叉成员不可拆开冒充独立结果。添加其他粒度须有对应 SQL 或支持下钻的指标模板，缺少执行能力时在选择器及校验中给出原因，禁止静默跳过。

WHEN 切换“展示不拆分维度的数据”，THEN 只改变结果展示与新分析的默认输入，不修改查询签名、不重新取数。整体数据来自实际整体 SQL，不从分层结果汇总推导。仅有带维度的完整 SQL 时开关不可用；没有任何可展示的拆分时不能隐藏唯一整体结果。

WHEN 保存能力草稿、载入已有能力、刷新或发布能力，THEN 保留维度来源、独立/交叉成员、启用状态、取值条件和整体展示设置；载入时重建对象引用，固定发布版本和已有分析不变。展示定义修改后复用原始数据，但核对表必须应用当前定义后才能重新确认。

维度卡的“更多设置”保留每个成员的引用版本、查看/复制 SQL 与草稿编辑入口，交叉成员也可逐一管理。复制维度 SQL 替换当前引用时，已有拆解条件迁移到新维度 Key。指标内置维度必须保留其所属指标组，失去所属组后提示修正，不再作为公共维度继续执行。选择器支持 Esc 或点击外部关闭；没有实际整体 SQL 时开关显示关闭且不可用。

SQL 或查询配置变化使当前取数失效，展示定义变化要求重新核对。空数据、权限不足、错误、错类型、实体重复或关联缺失不能发布。

## 简洁的管理入口

能力目录沿用内置 RPC 的单行卡片样式：取数能力标签、名称、指标数量、来源、版本／草稿状态与更新时间，右侧保留操作入口。RPC 标题显示“提供 N 个指标”，SQL 能力显示“已配置 N 个指标”，本次试跑的勾选数留在展开明细。自定义能力删除卡片下方的完成情况说明和 Key／业务目标／指标来源数量行，名称点击与「展开／收起」操作保持一致，编辑使用独立入口。能力定义与编辑页说明保持；所有能力均提供展开明细、指标和维度选择及指标全选。长时间文本省略并通过悬浮提示读取，窄屏在标题栏内自然换行，不增加表格、详情抽屉或新目录模块。

来源标签仅内置 RPC 蓝、内置 SQL 绿、自定义 SQL 紫，标签和筛选共用目录对象的来源分类。每个模块只显示一个来源标签；用户新建的完整配置属于自定义 SQL，内部引用内置 SQL 不改变整个对象的分类。内置 SQL 按创建人权限编辑，RPC 定义只读。不增加系统预置／自定义模块标签或模块类型筛选。

## 自定义 SQL 能力单页流程（2026-10-22，当前生效）

自定义能力内部只维护一个完整 SQL 草稿。点击“校验并解析 SQL”后先校验三项基础信息和非空 SQL，再展示模拟 AI 异步解析状态；成功后同时生成可编辑指标、普通维度及每个普通维度的拆分 SQL。解析失败保留全部输入和最近人工配置。示例 SQL只读取本地生成的 `demo_orders`／`demo_users`，不接真实表或模型服务。

演示维度补齐：成功解析的完整 SQL 没有维度时，Mock 默认补充“消费力分层（consumption_level）”“生命周期（lifecycle_stage）”“八大人群（user_segment）”三个可编辑维度；已解析的旧示例在打开编辑页时自动补齐，不要求重填 SQL。示例定义集中在 `singleSqlMockDimensions`，名称、Key、说明、拆分 SQL 和主动交叉组合沿用原交互。输入 SQL 保持，示例拆分查询用固定 mock 值补充对应输出列，不把示例分层声称为真实用户分层。已有维度不补齐，不重复添加；人工删除后普通刷新不重新添加，相同 SQL 的重解析保留 mock 维度的人工名称及 Key；修改 SQL 或恢复示例重新进入解析流程。既有发布快照、记录及分析引用保持。

指标表包含指标名、指标类型、SQL 字段／表达式、指标描述和操作；中文名称与描述由解析 mock 自动填入，支持编辑、添加、复制、删除、上移和下移。本期指标类型只使用 SQL 原值，不引入计算指标配置。

维度表包含维度名、维度 Key、维度描述、拆分 SQL 和操作；名称、Key、描述及拆分 SQL均可由创建人编辑。查看拆分 SQL 使用抽屉，非创建人只读。维度枚举值及其查询入口不渲染。

交叉维度每组从当前普通维度中主动选择 2–3 个不同维度，最多三维叉乘。“新增交叉维度”可连续新增多组，已有未完成组不阻止新增。新组默认展示维度 A、B，可添加或移除维度 C；各组独立生成、修改和删除，生成期间禁用当前组的编辑操作。空选择、组内重复维度、已失效维度、超过三个成员及重复组合不能生成；组合去重忽略成员顺序，两维和三维组合可同时存在。成功后支持修改维度及查看／编辑 SQL，修改维度需重新生成。未完成组随草稿保存并在刷新后保留，试跑和发布须拦截未完成或无效组，不能静默遗漏。生成 SQL、试跑任务、发布快照、草稿差异和分析引用都保留全部 2–3 个成员。兼容历史双维组合的存储结构，既有发布快照保持原样。系统只生成主动选择的组合，重新解析完整 SQL 时仅保留仍有效的组，已生成组重新生成 SQL，未完成组保持待生成；删除普通维度同步移除引用它的交叉组，修改维度 Key 同步更新成员引用。

保存草稿要求三项基础信息有效，但允许 SQL 未完成、尚未解析或没有指标／维度；草稿不进入分析模块可引用版本。校验并发布只检查三项基础信息、SQL 非空、当前 SQL 语法与解析成功、至少一个指标，以及没有未完成的交叉维度 SQL；不要求先试跑、结果核对、权限／高密数据、钱效口径或维度枚举值。发布快照仍进入既有分析模块的固定版本选择，既有分析引用不会自动升级。

## 过往分析报告与 AI 追问（2026-10-22）

「过往分析报告」入口为 `#/history`，报告详情为 `#/report/:id`。在现有主区域直接渲染，沿用系统侧栏与顶栏。复刻用户上传 `M-Sense报告AI追问demo.html` 中的两份完整示例报告（券批次核销、老客复购），包含分析结论、实验信息、数据表、实验组切换、转置和全屏；列表支持名称／实验 ID 搜索、类型、时间和我的／全部筛选。仅接入上传文件中有完整正文的报告，不将模块试跑记录加入本列表。

WHEN 打开报告，THEN 右侧报告追问助手常驻固定；桌面宽度 420px，可加宽到 560px，正文给助手预留宽度。正文和对话记录分别滚动，输入区固定在助手底部。1100px 以下改为底部固定输入区，可展开／收起对话，正文保留底部空间。

WHEN 点击分析模块的「继续追问」「向 AI 提问」或「让 AI 解读」，THEN 显示当前模块的推荐问题和自定义输入，回答嵌入当前模块卡片。模块追问独立于右侧会话，支持继续追问、停止、清空及「转到对话框继续」；转入时携带已完成问答和模块范围，同一回答不会重复转入。

WHEN 在右侧输入或选择推荐问题，THEN 显示读取／生成状态及逐步输出，支持停止、复制、重新生成和新对话；Enter 发送，Shift+Enter 换行，输入法组合输入期间不触发发送。追问范围可选择整份报告或某个模块，完整报告内容作为上下文。正文同一模块内选中文字可「追问这段」，输入区保留可移除的引用；回答中的引用标签定位并高亮报告原文。

会话、模块问答和输入草稿通过当前标签页 `sessionStorage` 键 `msense-report-followups-v1` 保存，按报告 ID 与模块 ID 隔离。切换报告／退出报告立即取消生成；刷新及返回恢复已有会话。新对话只清除右侧会话，模块清空只清除当前模块问答。这些追问不修改原始报告、能力发布快照和试跑记录。

本期是前端交互 Demo，报告数据抽取自上传文件，本地规则模拟回答，无真实模型调用。回答适配器位于 `src/report-history.js`，示例数据、问题和内容渲染位于 `src/report-demo-content.js`，样式限定在报告模块内。

## 2026-11-05 取数能力线上对齐

本节以本次线上站点与截图为准，更新此前目录展示口径。默认目录精简为六条代表性案例：创建人可编辑的已发布自定义 SQL、自定义 SQL 草稿、他人创建的只读自定义 SQL，以及实验背景、核心指标、领券/核销分布等内置能力。保留此前本地数据、稳定 Key、发布快照与直接链接；可在“演示环境”勾选“显示此前保存的能力”查看旧目录记录。本轮不修改报告 AI 与实验分析模块。

`/?demo=capabilities-20261105#/capabilities` 提供独立浏览器存储的六条案例预览入口；常规 `/#/capabilities` 继续使用已有工作区。两者复用同一工程与交互实现。

WHEN 打开取数能力目录，THEN 展示创建人、来源、业务目标、发布状态与关键词筛选；来源包含内置 RPC、内置 SQL、自定义 SQL。卡片显示实际配置的指标和取数维度数量、创建人、更新日期、发布版本；主要入口为试跑取数、展开/收起、自定义 SQL 查看；编辑收进更多，仅创建人可用。

WHEN 展开能力，THEN 指标与取数维度并列展示。指标默认未选，维度默认勾选整体；整体可与下钻同时选择，“仅保留整体”取消其他维度。进入试跑工作区后可再次选择字段；未在目录选择指标时，工作区默认选择该能力全部指标和整体。执行结果只包含本次选择的指标与粒度，历史试跑按创建人权限显示。

WHEN 查看或编辑自定义 SQL，THEN 复用同一页纵向配置：基础信息、11 个实验上下文、完整 SQL、输出指标、整体和拆分维度、交叉维度及发布记录。独立“校验 SQL”只检查语法，不替换已配置字段；“校验并解析 SQL”生成可编辑指标、维度和粒度 SQL。解析以实际输出为准，不为任意 SQL 注入未输出的维度。指标可调整名称、描述、展示格式、排序、复制和删除；只读页可查看字段和粒度 SQL。整体 SQL 与拆分 SQL均可编辑。新建保存后生成稳定 Key，校验通过可直接发布，交叉 SQL 未完成或重复时阻断发布。

数据与权限为本地演示：SQL 在 SQLite 示例底表执行，内置能力保留固定示例结果，解析文案模拟 AI 配置建议。本轮没有接入生产 SQL、实验数据、模型与发布服务。

## 层级

### 2026-11-05 新增：多实验分析

依据：[核心诉求与建设上下文](https://feishu.doubao.com/docx/Xuoud2peVoYOq6xFis5cdJwGnEf)（读取版本 15）、[m-sense 11月交付细节对齐](https://bytedance.larkoffice.com/docx/UxaMdLSlLop7HvxFd6CcKSwLnUc)（读取版本 470）。本节定义新增能力，已有单实验分析、报告追问、取数配置沿用原规则。

#### 产品对象与完成条件

分析人员在同一业务目标下选择多个独立实验，比较各实验策略的表现及配置差异，形成能追溯到单实验对照组和数据的多实验报告。多个实验组不能代替多个实验。交付覆盖：管理端模板与模块类型、工作台多个实验和观测时间输入、可选补充信息、多实验报告呈现。

本轮为展示与交互 Demo，使用 3 个独立虚拟实验，不连接生产取数和模型，不复制生产样例的实际实验 ID 或数据。报告、对比表、实验明细与追问共用同一份模拟数据；明显展示“模拟数据，仅供 Demo 展示”。

#### 已确定范围与设计假设

两份来源已确定管理端/工作台/报告端范围，以及比较同一业务场景下不同策略。以下具体设计是本轮评审方案，尚未成为已确认的生产规则：

- [Confirmed, 2026-11-09] 多实验仅逐实验设置观察窗口，不提供全局日期或统一应用入口；每个实验保存独立日期。未指定时使用该示例实验完整实验期。观察窗口允许包含实验后的追踪时间，报告同时标明实验期与观察期。
- [Assumption, TBD] 总体对比、策略差异、实验明细为三个可切换视图；报告正文不串联拼接多个旧报告。
- [Assumption, TBD] 多实验至少包含 2 个不同实验。部分失败时保留失败记录，至少 2 个实验成功才可展示横向比较；单个成功实验保留数据但提示补充实验或修复失败项。
- [Confirmed, 2026-11-08] 单实验模板仅引用单实验模块；多实验模板可混选单实验和多实验模块，至少包含一个负责跨实验结论的多实验模块。模块引用固定发布版本；跨实验模块描述对比顺序、关注指标和解释边界。
- [TBD] 实际首批实验/策略案例、真实 ID 映射、生产观察时间规则、策略可比性标准及最终报告布局须在评审中确认。

本轮模拟实验分别声明数据覆盖窗口；观察时间可以包含实验后追踪期，但超出示例覆盖范围时明确阻断，不延伸生成不存在的数据。日期变化重新计算模拟累计指标，逐实验显著性为固定演示字段，未根据新窗口重新检验。

#### MA-01 管理端类型与模板

WHEN 查看实验分析模块列表（`#/modules`），THEN 按 `https://msense.bytedance.net/analyst/modules` 及 2026-11-09 用户截图展示紧凑表格，替换此前的模块卡片。页头只显示标题及右侧“新建实验分析模块”，下方直接排列名称/说明搜索、创建人、有效状态、分析类型及排序筛选，不套筛选卡片。表格为“名称与说明 / 业务目标 / 适用端 / 状态 / 创建人 / 更新时间 / 操作”七列，名称表头显示筛选结果总数；说明在名称下方灰色显示，创建人来自既有身份数据，更新时间按 `YYYY/MM/DD HH:mm` 展示。行内保留复制、编辑、上下线及归档入口；表尾提供每页条数及上一页/下一页，筛选联合生效并重置到第一页，窄屏保留表格横向滚动。与实验报告模板列表复用字号、行高、筛选控件及表格样式。

WHEN 查看实验分析模块列表，THEN 名称/说明搜索框右侧提供“全部创建人”下拉筛选。下拉支持搜索当前未归档模块中已有的创建人，选择后与关键词、有效状态、分析类型共同筛选；切回“全部创建人”仅清除创建人条件。创建人来自模块 `createdBy`，新建与复制模块记录当前执行身份，旧记录不因筛选而改写。

WHEN 新建或编辑实验分析模块，THEN 可选择“单实验分析”或“多实验分析”类型。已有模块默认单实验，类型进入发布配置；复制保持类型。多实验模块分析思路聚焦跨实验策略表现，禁止将指标直接求和作为横向结论。

模块表单按行展示：第一行“模块名称 / 模块说明”，第二行“业务目标 / 适用端（可选）”，第三行单独展示“分析类型”，下一行展示“取数模块”。窄屏按相同字段顺序纵向排列。

WHEN 新建或编辑实验报告模板，THEN 按 `https://msense.bytedance.net/analyst/reports/new` 及 2026-11-08 用户截图复刻：页头显示返回、模板名称、保存状态、保存草稿及发布新版本；正文左侧依次展示“模板名称 / 模板说明”“业务目标 / 适用端（可选）”“分析类型”“实验分析模块”“当前可用指标与下钻维度”“分析思路（可选）”“注意事项（可选）”，右侧展示版本记录及已组合模块数量。基础信息及模块配置不再套步骤卡片，不展示额外的章节名称/内容/版本表单。

分析类型为唯一新增字段，使用与实验分析模块一致的下拉样式，选项为“单实验分析 / 多实验分析”；新建默认单实验，已有模板保留类型。添加模块使用居中双列多选弹窗，支持名称/说明及类型名称搜索，展示已上线状态和分析类型。单实验模板仅提供当前业务目标下的单实验模块，多实验模板同时提供当前业务目标下的两类模块，可同时点击选中；新增选择使用当前线上版本，已选模块保留固定版本。点击完成后应用选择，关闭弹窗不应用；搜索不会清除不可见的已选项。模块按列表顺序执行与展示，可上移、下移及移除；汇总按引用的固定版本展示指标与下钻维度，整体不计入下钻数量。切换类型保留原模块，单实验模板含多实验模块时提示类型不一致，多实验模板缺少多实验模块时提示至少需要一个负责跨实验结论的模块。

适用端、分析思路及注意事项随草稿保存、复制和版本发布配置持久化；既有版本按缺省字段兼容读取，旧报告快照不变。

WHEN 查看实验报告模板列表（`#/templates`），THEN 按 `https://msense.bytedance.net/analyst/reports` 的管理页样式展示：标题右侧为“新建实验报告模板”，下方直接排列名称/说明搜索、可搜索的创建人、有效状态、分析类型及排序筛选，取消卡片和标题说明。分析类型是本地新增的筛选项，沿用“全部分析类型 / 单实验分析 / 多实验分析”的下拉入口。

列表使用“名称与说明 / 业务目标 / 适用端 / 模块数 / 状态 / 创建人 / 更新时间 / 操作”八列表格，名称旁显示筛选结果总数，表尾提供每页条数和上一页/下一页。筛选联合生效且重置到第一页，窄屏保留表格横向滚动。数据沿用本地模板，未配置适用端显示“不限端”。

WHEN 在模板行中操作，THEN 编辑进入现有配置页；草稿上线先通过发布校验，已下线模板上线校验其固定发布版本，不顺带发布待发布修改；下线后不能发起新分析。归档使用二次确认，确认后从列表与新分析模板选项移除，已生成报告保留快照。

WHEN 模板没有有效模块、模块未发布/已下线、单实验模板包含多实验模块、多实验模板没有有效的多实验模块或必填信息缺失，THEN 可保存草稿但不能发布或发起分析；逐项说明原因。移除最后一个多实验模块后仍可保存草稿，不能发布新的纯单实验模块组合；此前发布版本和已有报告继续保留。类型校验以引用的固定发布版本为准，不受模块当前草稿类型修改影响。

#### MA-02 工作台实验集合输入

WHEN 进入实验分析，THEN 按 2026-11-08 首页截图展示居中欢迎语、“实验报告模板”卡片、“实验分析模块”卡片及底部实验输入面板，不使用步骤面板或右侧摘要。首页下拉筛选支持“全部 / 单实验分析 / 多实验分析”，默认全部，并同时作用于模板、模块及已上线数量；分析模块默认展示前 12 项，余项可原位展开与收起。筛选独立于任务分析类型，切换筛选不修改已选配置或实验输入；实际任务类型由所选模板或单独模块的发布版本确定。新会话的默认模板为单实验，既有草稿保留类型。当前单独模块组合仍要求类型一致，不将“全部”保存为任务分析类型。

WHEN 选择模板或单独模块，THEN 模板单选与单独模块多选互斥，选择单独模块不创建隐含模板；开始分析时固定所选模块的当前线上版本与顺序，生成正式报告。模块未上线、已下线、已归档、类型或业务目标不一致须阻断；管理端模块试跑继续使用模块草稿快照并保存私有记录，不能混入正式报告列表。

WHEN 使用单实验类型，THEN 直接填写实验 ID 和观察开始/结束日期，输入与配置有效后启用“开始分析”。多实验类型通过全宽批量输入添加实验 Libra ID，批量输入区只展示 ID 输入及解析入口，右侧不展示全局观测时间，也不提供统一应用日期的入口；日期仅在解析后的各实验分析项右侧逐项设置，模块试跑沿用同一规则。支持逗号、中文逗号、空白和换行分隔；保留重复 ID 的输入意图，以便选择同 ID 下不同钱效中心录入项，不在 ID 解析阶段直接合并。初始不展示空实验明细，补充信息默认收起，示例数据入口保留在输入区。

WHEN 批量解析实验 ID，THEN 按 `https://msense.bytedance.net/` 及 2026-11-09 用户截图二至四复刻解析区域。每个实验以“实验 ID / 观测时间”一行展示，ID 右侧的叉号移除该实验；观测日期控件显示“开始 / 结束”、中文日期及日历图标。其下灰色摘要条只展示实验名称、实验周期和观测结束日期限制，不展示业务目标、适用端、人群、对照组详情或策略组选择；策略组沿用该实验已配置的有效组。多个实验纵向排列，各自保留观测日期。

WHEN 同一个实验 ID 匹配多个钱效实验，THEN 在该实验日期行下展示“钱效实验候选项”下拉，候选文本为“名称 · 开始日期 至 结束日期 · 钱效实验 ID”。首次解析不自动选择，显示灰色选择提示，观测日期为空，开始分析不可用；选择后展示对应摘要并填入该候选的实验期作为默认观测日期。切换只重置该实验的候选、日期及内部组配置，不改动其他实验；提交时冻结选择的钱效实验 ID 与对应定义。单一匹配不展示候选下拉。既有已保存输入及历史任务按原定义兼容，不要求重新选择。

WHEN 去重实验分析项，THEN 唯一组合为“实验 Libra ID × 钱效中心录入实验候选项 ID”，不按 Libra ID、实验名称或观察日期单独去重。同一 Libra ID 下不同候选可同时分析，例如 `DEMO-001 × DEMO-001-QX-01` 与 `DEMO-001 × DEMO-001-QX-02` 是两项；同 ID、同候选即使观察窗口不同也不能重复添加。候选名称相同不影响身份判断，数量按完成选择的有效组合计，不将共享 Libra ID 的分析项解释为样本相互独立的重复实验。

WHEN 为已有 ID 添加其他候选项，THEN 可在批量输入中再次解析该 ID，或点击所属行的“添加其他候选项”，新增一行待选择项，各行使用稳定行身份管理候选、日期与删除。已有选择和日期不被覆盖；已被其他行选择的候选禁用并标记“已添加”，程序校验同样拦截重复组合。可用候选都已在列表中时不再新增行，提示无可新增候选项；单匹配重复输入沿用已存在组合。不会自动分析尚未选择的候选；移除或切换一行只影响该行。

WHEN 修改某个实验的观察窗口，THEN 仅更新该实验，提交时保存最终逐实验日期；切换分析类型或解析新增 ID 不将旧的全局日期覆盖到实验行。日期缺失、无效或开始晚于结束、业务目标不一致、候选未选择或无效、内部策略组配置缺失均须阻断；日期问题在所属实验行提示。页面提示及原生日历边界沿用本地示例的数据覆盖范围，不将线上“结束后 30 天”规则用于生成超出示例覆盖范围的数据。

WHEN 用户填写补充信息，THEN 作为分析背景保存，不覆盖结构化实验配置、数据和计算口径；报告显示该信息的用户补充来源。

未知实验 ID 显示解析失败，不自动伪造实验身份或映射。演示入口提示使用 DEMO-001/002/003；支持一键填入示例。DEMO-001 以两个虚拟钱效实验候选演示同 ID 多匹配，两者使用相同底层模拟指标、不同实验周期，候选 ID 明确标为 DEMO。单实验类型只接受 1 个分析项，多实验至少 2 个有效的 ID × 候选项组合；同一 ID 的两个不同候选满足多实验输入数量要求。

#### MA-03 分析任务与失败恢复

WHEN 点击生成报告，THEN 冻结模板/模块版本、实验集合、策略组、日期及补充信息，逐实验展示待开始/取数中/分析中/成功/失败状态。生成期间避免重复提交，并提供清晰进度。

WHEN 同一 Libra ID 的不同钱效候选进入任务，THEN 每个组合独立冻结候选定义、组别和观察窗口，结果及计算执行上下文均保留该候选身份；结果匹配、成功计数和重试以组合为单位，不按 Libra ID 回填。任务列表和输入快照展示候选 ID，失败项不能复用同 ID 另一候选的成功结果。只有一个同名 ID 的历史任务可按既有 ID 结果与固定定义兼容；重复 ID 缺少候选身份时标记不可用，不猜测归属，不补算历史数据。

WHEN 一个实验失败，THEN 保留已成功实验及失败原因；“重试失败项”只处理失败项。用户修改实验集合、观察日期或模板时视为新任务，不将旧成功结果混入新快照。

WHEN 至少 2 个不同组合的分析项成功但存在失败项，THEN 可展示已成功分析项的部分对比报告，报告头明确成功/失败数量，失败项不出现在对比值中且保留失败列表。成功不足 2 个组合则不生成伪横向结论。

#### MA-04 多实验报告呈现

报告头展示标题；多实验报告在标题下按实验输入快照顺序自上而下拼接每个实验的信息行，每行依次为“实验名称 / Libra ID / 实验周期 / 观察窗口”。实验周期来自该实验定义，观察窗口来自该实验的输入日期，分别展示，不共用或合并不同实验的日期。失败实验同样保留在表头，模块内切换实验不改变表头的完整实验集合。窄空间按两列或单列展示，字段顺序保持一致。分析类型、业务目标、模板版本、实验数量、生成时间及数据状态在信息行下方轻量展示。报告正文按模板顺序由单实验及多实验分析模块组成，执行及展示方式取决于模块固定发布版本的分析类型。

WHEN 展示多实验报告，THEN 与单实验报告保持相同的整体顺序：报告表头 → 报告级“实验核心结论” → 按模板顺序展示各分析模块。核心结论默认展开，复用单实验报告的卡片、标题、段落/小标题/列表与右侧 AI 入口；目录仍保留原有模块编号，不将核心结论计为分析模块。该区域覆盖整份报告，概述整体效果与钱效、其他模块发现和数据完整性，不依次拼接所有实验的完整模块结论，也不替代模块内保留的分析结论。适用于全部 Demo、混合模块及新生成、历史多实验报告。

WHEN 汇总报告核心结论，THEN 仅引用该报告固定快照中已选且展示的指标、维度和已保存结果；有已保存的报告级结论时保留其正文。缺少旧报告结论时在阅读阶段汇总，不能回写旧报告、使用当前模块草稿补算或借用未选指标。矩阵报告与明细表共用可对齐的固定证据，无法对齐的字段保留原因，不将异常数值写入核心结论。失败实验、模块不可用、字段缺失保留原因；显著性只沿用实验自身已保存结果，不推断跨实验显著性，不套用未配置的 ROI 达标阈值或直接断言最优策略。切换模块实验、表格分组、指标范围或转置不改变报告核心结论。核心结论的 AI 追问进入报告助手，引用可返回该卡片且不改变模块选择。

WHEN 报告包含同一 Libra ID 的不同钱效候选，THEN 表头各自保留该候选信息并补充“钱效实验 ID”；单实验模块的下拉选项、综合结论、矩阵一级列头与显示范围使用 Libra ID + 钱效候选 ID 区分，各候选下挂自身组别。独立保存各项的数据、阅读状态、计算结果和 AI 引用，即使实验名称、Libra ID、组 ID 与日期相同也不能合并或串联。只出现一次的 Libra ID 保留原有实验身份与证据锚点；多实验模块展示统一遵循下述大表格规则。

WHEN 多实验报告引用单实验模块（例如 Pre AA），THEN 对 A、B、C 按实验输入顺序分别运行并保存数据；展示时使用“查看单个实验”下拉框，每次只展示当前实验的单实验结论与数据，也不生成本模块的跨实验综合结论。下拉选项按输入顺序显示完整实验名称及 Libra ID，不使用并列实验 Tab；控件在当前内容宽度内展示，悬停可查看选中实验的完整名称与 ID。各单实验模块独立切换，切回某个实验时恢复其表格分组和转置状态。失败实验保留可选项，选中后显示原因，其他实验仍可切换查看；目录或 AI 引用跳转先选中目标实验，再定位其固定证据。

#### MA-05 对比与证据规则

各实验指标以自己的对照组计算。支付天(DAC)、人均支付 GMV 的增幅 =（策略组值 / 对照组值 − 1）×100%；增量累计 DAC =（策略组 DAC − 对照组 DAC）× 策略组进组用户数；增量日均 DAC = 增量累计 DAC / 观察天数；单增量 DAC 用增成本 = 本实验补贴 / 本实验增量累计 DAC；增量支付 GMV =（策略组人均支付 GMV − 对照组人均支付 GMV）× 策略组进组用户数；GMV-ROI = 本实验增量支付 GMV / 本实验补贴。

上述为本轮虚拟数据的统一模拟口径，实际数据以生产取数能力登记口径为准。显著性为逐实验模拟字段，不通过跨实验排序、均值或增幅差值推断。不得直接合计各实验 GMV、增量人数、补贴或 ROI。未设置生产统一 ROI 达标阈值。

多实验结论 AI 入口引用当前模块；单实验结论 AI 入口引用当前模块与实验 ID。回答中的引用携带固定实验 ID，点击时恢复对应模块的实验选择并定位证据，不受之后的下拉切换影响。推荐追问和回答留在右侧 Agent，正文不追加问答内容。新模块报告的 Agent 初始收起；旧单实验报告继续沿用原交互。

所有多实验报告从固定数值证据形成已登记的整体展示快照，明确记录来源身份及版本、整体粒度、指标 key、单位、精度；计算指标同时记录已保存公式及输入来源口径。已有矩阵快照时直接沿用，包括明确保存的空快照；没有矩阵快照的新生成及历史报告在阅读阶段由当时配置和结果投影，不回写报告、不重新取数或计算。不解析格式化文本，不按标题、名称或数组位置拼接，不由批次分位数合成整体。版本、粒度、单位、定义或依据不一致的单元格不参与对齐，保留原因及原始快照。主值按来源精度显示；增幅和显著性只保留相对本实验自身对照组的已保存字段，不生成新的跨实验显著性或排名。

多实验模块的单元格证据身份包含模块、数据集、实验、组别和指标。旧单实验结论区域引用转到模块多实验结论；旧逐实验及数据表引用转到大表格中的对应原实验证据，必要时恢复被引用的隐藏列，不恢复已移除结论或实验下拉。来源及数值身份通过表头、单元格悬停文本和 AI 引用保留；不再显示表格下方的提示区域。引用保留转置方向，其身份不随阅读状态改变；单实验模块继续按原规则先选中实验再定位数据。0、未提供、不适用、失败与无法对齐分别呈现；失败实验的可恢复组身份仍保留，有效实验数按当前指标表及显示范围计算，不足两个时只展示已有数据和提示。阅读操作不修改固定快照、模板或结论。

混合报告预览为 `#/report/r-mixed-modules`，包含单实验 Pre AA 模块（3 个实验通过下拉框切换）和多实验核心表现模块。可编辑模板样例为 `#/templates/demo-template-mixed`。PreAA 使用独立保存的实验前虚拟数据及日期，按当前策略组选择保留对照组和所选策略组；不从实验后的指标反推、不随实验后观察窗口变化、不为未保存该证据的历史报告补算。当前只提供汇总指标，没有 PreAA 方差或显著性检验，不宣称 AA 通过。

#### MA-06 历史报告

报告类型筛选固定为“全部类型 / 单实验报告 / 多实验报告 / 单模块报告”；原“实验报告”统一显示为“单实验报告”，列表及报告详情的类型标签同步。旧数据中的“实验报告”兼容映射至“单实验报告”，继续参与同一类型筛选。

## SQL 配置与指标组（2026-10-22）

按用户最新纠正，自定义 SQL 表单的顶层只有“指标”和“维度”两个大区块。指标 SQL 配置器、上下文入参绑定、字段设置、解析操作和指标表均位于指标区内；自定义维度的 SQL 配置器、实体映射、参数绑定、解析操作和维度表均位于维度区内。SQL 配置不再独立为顶层栏目，维度 SQL 不再使用单独浮层。指标字段与角色总表仍位于指标 SQL 配置内的“SQL 输出字段”。编辑器只进行语法校验与静态字段解析，不执行查询、不获取样本行、不产生取数记录；权限、空值、真实类型和粒度拦截由试跑模块完成。已关联 SQL 保存后返回能力组整体试跑；现有独立 SQL 验证进入同一个浮层。

SQL 编辑器下方保留“校验并解析 SQL”与模板操作，“上下文入参绑定”放在解析操作下方、指标组上方。完整绑定默认折叠，显示已绑定数量；有未绑定或类型不匹配项时自动展开。同名目录参数自动绑定，未知名称不猜测来源，例如 `${date}` 不自动绑定到观测开始日期。这里仅选择参数来源，实际值在取数验证浮层填写。类型来自静态表达式与已知字段定义，无法确定时交由 DS 确认；枚举仅解析 SQL 显式常量或由 DS 填写，实际取值在试跑结果核对。

指标表只展示指标名、计算类型、表达式与行操作。支持新增、复制、删除和上下移动；Key、口径、格式、精度、单位、空值显示和比较展示收进“更多设置”。“一键解析配置指标”先解析当前 SQL，再补齐未配置的数字指标，保留现有名称、表达式与人工设置。模板入口提供聚合 SQL、用户粒度指标 SQL 或维度 SQL，应用时替换当前 SQL 与指标配置。

维度大区块保留“指标内置／公共维度／自定义 SQL”三类来源，支持选择、新建独立 SQL、拆解条件、整体展示与显式交叉。点击自定义来源中的“新建 SQL 维度”或已有能力内维度的“编辑 SQL”，在此大区块内展开自己的 SQL 配置器和维度表，解析入口位于该编辑区内；“保存维度”应用配置，“取消编辑”丢弃临时改动。区块也展示当前指标 SQL 自带的维度，可修正名称、类型或将其他实际输出设为维度；Key 与口径沿用“更多”设置。未关联能力的独立 SQL 仍展示指标和维度两大块，关联能力后可使用三类下钻来源。

WHEN 点击区块内一键解析，THEN 处理当前 SQL 并刷新对应配置与能力引用；旧异步结果不覆盖新 SQL，解析失败保留最近成功字段与人工配置，不新增运行或发布记录。维度解析不凭空从完整 SQL 生成其他粒度；数字字段的维度角色仍由已知定义或 DS 修正决定。当前原型使用已有静态解析器承接一键配置，尚未接入模型服务。

WHEN 解析成功，THEN 将 SQL 实际输出保存到 `draft.fields`，将独立指标定义保存到 `draft.metricDefinitions`。旧配置和已发布快照通过适配继续按 SQL 原值取数，不重写历史定义。同一数字列可以派生多个指标。

WHEN 配置指标计算类型，THEN 支持 SQL 原值、SUM、AVG、UV、A / 进组用户数、A / B 与进组用户数。A / 进组用户数和 A / B 可以选择 SUM、AVG 或 UV 聚合；UV 计算所选数字字段大于零的去重实体数，SQL 必须输出对应实体 ID。聚合按实验组和已声明的维度联合计算，不自动汇总 SQL 原值指标；混合聚合时原值仅在唯一来源行时保留。

WHEN 使用用户粒度模板，THEN 从实验全量示例用户出发，左关联观测窗口订单，保留零订单用户；默认生成 User、订单量、人均订单数、订单渗透和下单用户数。自定义 SQL 的进组人数取决于其实际覆盖的人群，不能把仅有订单的用户当作全量进组人群。

WHEN 重新解析或 SQL 暂时解析失败，THEN 保留人工指标配置。已删除指标不会被重解析恢复；引用字段消失时显示失效字段并阻止试跑、发布，DS 修正后再继续。指标名称、格式与精度改变后可复用当前原始结果，但核对表立即应用新定义并要求重新核对；计算表达式或来源改变后需要重新取数。指标定义随能力关联、保存草稿、载入已有能力、固定发布版本与分析输入完整传递。

保留四种已有 / SQL 指标维度组合和三种维度交叉来源。模板组合保留明确的 SQL 位置，交叉实际关联明细并联合分组，禁止从独立汇总推导。完整查询仅提供自身的实际粒度，增加其他下钻需另行提供相应 SQL 或模板。

组合名称和 Key 自动生成；Key 只读，在能力保存后收在“更多设置”，与选填说明和“查看绑定 SQL”一起展示。成员、唯一性和实际粒度必须校验，说明不新增发布阻断。字段的单位、空值和比较展示收在“更多”；对照组比较指标可以显示“—”，普通基值保持展示，原始 SQL 值不变。

## 维度选择与交叉（2026-10-22）

能力配置将“下钻维度”和“下钻分组”合并为“维度”。参照 Libra 的就地选择器、浅底维度卡、堆叠交叉卡和整体数据开关；不另设一张重复配置表。前一轮交互依据用户截图；本轮已成功访问 Libra 实验 4823214 的 adhoc 页面，并核对“SQL自定义维度”弹窗。

维度选择器支持搜索，按“指标内置 / 公共维度 / 自定义 SQL”分栏。指标内置只列出已选指标组自带的维度；公共维度由平台维护；自定义 SQL 包括可复用的已发布维度、当前能力内维度，以及指标 SQL 自带的实际输出粒度。当前内置 SQL 指标组提供消费力分布，公共目录提供生命周期和城市 ID。原目录 RPC 仍保持固定样例边界，不凭空为未接入的 RPC 生成 SQL。

WHEN 多选普通维度并添加，THEN 每项生成一张独立卡和独立 SQL 变体，彼此不隐式交叉。重复添加同一个独立维度不可产生重复任务。

WHEN 点击“交叉维度”，THEN 在一个卡片中显式选择 2–3 个不同成员，可新增多组、跨来源选择；保留已有独立卡，各组交叉单独执行。每个成员支持移除，成员不足两个或超过三个时阻止试跑与发布。交叉名称自动由成员生成。

WHEN 维度有已知枚举值，THEN 卡片“拆解”默认全部取值，可选择部分值；条件作用于对应变体的 SQL 输出，不改变整体查询。字符串、数字、NULL 保持原生值与类型；空选择、失效字段或类型不匹配必须校验。

WHEN 完整 SQL 已输出单维或交叉粒度，THEN 作为一张绑定 SQL 的维度卡，可选择是否启用；交叉成员不可拆开冒充独立结果。添加其他粒度须有对应 SQL 或支持下钻的指标模板，缺少执行能力时在选择器及校验中给出原因，禁止静默跳过。

WHEN 切换“展示不拆分维度的数据”，THEN 只改变结果展示与新分析的默认输入，不修改查询签名、不重新取数。整体数据来自实际整体 SQL，不从分层结果汇总推导。仅有带维度的完整 SQL 时开关不可用；没有任何可展示的拆分时不能隐藏唯一整体结果。

WHEN 保存能力草稿、载入已有能力、刷新或发布能力，THEN 保留维度来源、独立/交叉成员、启用状态、取值条件和整体展示设置；载入时重建对象引用，固定发布版本和已有分析不变。展示定义修改后复用原始数据，但核对表必须应用当前定义后才能重新确认。

维度卡的“更多设置”保留每个成员的引用版本、查看/复制 SQL 与草稿编辑入口，交叉成员也可逐一管理。复制维度 SQL 替换当前引用时，已有拆解条件迁移到新维度 Key。指标内置维度必须保留其所属指标组，失去所属组后提示修正，不再作为公共维度继续执行。选择器支持 Esc 或点击外部关闭；没有实际整体 SQL 时开关显示关闭且不可用。

SQL 或查询配置变化使当前取数失效，展示定义变化要求重新核对。空数据、权限不足、错误、错类型、实体重复或关联缺失不能发布。

主流程固定为：填写基础信息 → 引用实验上下文 → 编写一整套完整 SQL → 校验语法并模拟 AI 解析 → 人工确认指标和维度 → 每组主动选择 2–3 个普通维度生成交叉维度 SQL → 保存草稿或校验并发布。自定义能力页不再跳转到独立指标 SQL／维度 SQL 子页面，也不展示指标库选择、公共维度、指标内置维度、计算指标、钱效指标绑定、官方／非官方 SQL、权限切换、维度枚举值和获取枚举值。

SQL 编辑器上方的小标题统一为“可引用上下文”。上下文始终以单列列表平铺，解析成功后仍保持展开；顶部搜索框按名称、Key 和说明即时筛选，下方每行展示名称、占位符、简短说明、示例值及复制／插入操作，不使用双列、已选区或折叠数量入口。搜索无结果时提供清空搜索；清空后恢复全部条目，同一能力局部更新保留搜索，切换能力时重置。搜索不修改 SQL、配置或历史；插入沿用编辑器光标／选区替换逻辑。只读查看仍允许搜索与复制，插入继续按编辑权限控制。参数继续使用工程已有 `${libra_id}`、`${pgdp_experiment_id}`、`${start_date}`、`${end_date}` 命名和 mock 值。

自定义能力内部只维护一个完整 SQL 草稿。点击“校验并解析 SQL”后先校验三项基础信息和非空 SQL，再展示模拟 AI 异步解析状态；成功后同时生成可编辑指标、普通维度及每个普通维度的拆分 SQL。解析失败保留全部输入和最近人工配置。示例 SQL只读取本地生成的 `demo_orders`／`demo_users`，不接真实表或模型服务。

演示维度补齐：成功解析的完整 SQL 没有维度时，Mock 默认补充“消费力分层（consumption_level）”“生命周期（lifecycle_stage）”“八大人群（user_segment）”三个可编辑维度；已解析的旧示例在打开编辑页时自动补齐，不要求重填 SQL。示例定义集中在 `singleSqlMockDimensions`，名称、Key、说明、拆分 SQL 和主动交叉组合沿用原交互。输入 SQL 保持，示例拆分查询用固定 mock 值补充对应输出列，不把示例分层声称为真实用户分层。已有维度不补齐，不重复添加；人工删除后普通刷新不重新添加，相同 SQL 的重解析保留 mock 维度的人工名称及 Key；修改 SQL 或恢复示例重新进入解析流程。既有发布快照、记录及分析引用保持。

指标表包含指标名、指标类型、SQL 字段／表达式、指标描述和操作；中文名称与描述由解析 mock 自动填入，支持编辑、添加、复制、删除、上移和下移。本期指标类型只使用 SQL 原值，不引入计算指标配置。

维度表包含维度名、维度 Key、维度描述、拆分 SQL 和操作；名称、Key、描述及拆分 SQL均可由创建人编辑。查看拆分 SQL 使用抽屉，非创建人只读。维度枚举值及其查询入口不渲染。

交叉维度每组从当前普通维度中主动选择 2–3 个不同维度，最多三维叉乘。“新增交叉维度”可连续新增多组，已有未完成组不阻止新增。每组使用一个维度多选框：新组默认为空，打开后搜索、勾选，已选项显示为可移除的名称标签；点击标签的 × 可移除任意成员。取消维度 A／B／C 分栏及「添加第三个维度／移除第三个维度」操作，两维与三维使用同一交互。选满三项后禁用其他未选项，已选项仍可取消，少于两项时生成按钮不可用。每组仅保留维度组合、生成组合 SQL 和删除组操作；各组独立生成、修改和删除，生成期间禁用当前组的编辑操作。空选择、组内重复维度、已失效维度、超过三个成员及重复组合不能生成；组合去重忽略成员顺序，两维和三维组合可同时存在。成功后支持修改维度及查看／编辑 SQL，修改维度需重新生成。未完成组随草稿保存并在刷新后保留，试跑和发布须拦截未完成或无效组，不能静默遗漏。生成 SQL、试跑任务、发布快照、草稿差异和分析引用都保留全部 2–3 个成员。兼容历史双维组合的存储结构，既有发布快照保持原样。系统只生成主动选择的组合，重新解析完整 SQL 时仅保留仍有效的组，已生成组重新生成 SQL，未完成组保持待生成；删除普通维度同步移除引用它的交叉组，修改维度 Key 同步更新成员引用。

WHEN 使用交叉维度多选框，THEN 支持键盘打开、搜索、勾选和 Esc 关闭，关闭后焦点回到当前组；点击外部关闭，仅同时打开一个选择面板。逐项勾选时面板保持展开，搜索和焦点保留，不添加额外确认保存步骤；「完成」仅关闭面板。选择面板随滚动、窗口和手机视口调整位置，不遮住触发控件或被父容器裁切。仅查看及生成中的组不可修改，所有选择和标签移除动作仍检查创建者权限。

保存草稿要求三项基础信息有效，但允许 SQL 未完成、尚未解析或没有指标／维度；草稿不进入分析模块可引用版本。校验并发布只检查三项基础信息、SQL 非空、当前 SQL 语法与解析成功、至少一个指标，以及没有未完成的交叉维度 SQL；不要求先试跑、结果核对、权限／高密数据、钱效口径或维度枚举值。发布快照仍进入既有分析模块的固定版本选择，既有分析引用不会自动升级。

## 2.2 分析模块计算指标（2026-11-08，当前生效）

实验分析模块编辑页顺序为：名称／说明 → 业务目标／适用端 → 分析类型 → 取数模块 → 指标 × 维度及报告顺序 → 指标配置（已有指标／计算指标） → 分析思路／注意事项。未选能力且没有计算定义时不展示空配置区；已经存在的失效公式继续显示。计算指标行支持拖拽和上下移动，顺序决定后续实验报告数据明细中的计算指标顺序。

参考 Libra 的行内表格，计算指标主界面只有指标名称、计算类型、表达式三项配置。计算类型支持相加、相减、相乘、相除，默认相除；切换类型自动更新运算符并保留两个输入。表达式通过可搜索的指标选择框组成，第一项为指标，第二项为指标或固定数值。默认数值、两位小数、在报告中展示；数值／百分比、0–6 位小数和报告开关收进“更多”。不重复配置 SUM、UV、人天等取数聚合口径，不提供自由 SQL／脚本、嵌套表达式或计算指标互相引用。

WHEN 选择公式输入，THEN 候选只来自当前分析模块已选取数能力的固定版本，可搜索指标及所属能力；仅包含真实数值指标，维度、配置文本和显著性标签不可选。候选包括尚未勾选的合法指标，选中后自动加入该能力的取数范围并提示“已加入取数指标”，不自动加入新的能力。同名指标通过来源实例、能力版本及 Key 区分。

WHEN 取消输入指标勾选、移除来源或引用版本失效，THEN 保留公式并就地说明原因；允许保存草稿，阻止模块整体试跑和发布。删除公式保留原始指标勾选。名称、二元公式、显示格式及精度一起校验；未配置计算指标的旧模块沿用原有流程。

计算使用原始数值，每个实验、分组、观察窗口、整体／单维／交叉粒度独立计算。跨能力只有固定版本中具有兼容结构化粒度契约，且运行数据中的组合键唯一时才能对齐；不按字段名称、行号或展示标签关联，不合并重复行。缺少匹配行、输入为空、非数值、分母为零或非有限结果显示“—”并保留原因；有效 0 和负数正常保存。百分比仅改变显示，例如 2,000 ÷ 10,000 的原值为 0.2，显示 20.00%；计算结果不自动附加增幅或显著性。

模块整体试跑在原始数据之后追加按粒度分表的计算结果，保存公式、来源及原始输入。单能力试跑只检查原始能力数据，并明确未验证模块公式。单实验和多实验使用同一计算引擎，多实验任务按实验分别保存计算结果；报告读取固定结果，多实验模块展示遵循 MA-04 的两级大表格及对齐依据，公式与输入身份仍保存在结果证据中；单实验模块保留原计算表和独立实验切换。计算自身的报告展示开关与原始能力展示开关独立，隐藏原始能力数据仍可作为公式输入。

计算定义随模块保存、发布及复制。复制重映射来源实例引用，修改公式使旧试跑不再代表当前配置；旧记录明确标记为历史配置快照。已生成报告不从当前草稿补算或改写。旧报告没有保存计算结果时说明缺失，保持原快照。

本地 Demo 入口：`#/modules/calculated-metrics-demo` 展示“用户核销率”的三列配置和固定 20.00% 试跑；`#/modules/multi-calculated-demo` 配置独立实验的整体与消费力分层计算；`#/report/r-multi-modules` 展示已保存的多实验计算数据。多实验的取数仍以现有独立实验模拟能力为准，没有模拟数据的其他能力不会被替换或伪造。生产取数和模型服务尚未接入。

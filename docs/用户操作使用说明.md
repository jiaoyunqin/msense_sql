# M-Sense 自定义 SQL 基本使用说明

适用对象：配置取数能力的 DS、分析师。对应 2026-10-22 更新的交互原型。

[打开取数能力列表](https://msense-sql.vercel.app/#/capabilities) · [打开页面内配置流程](https://msense-sql.vercel.app/#/guide)

通常按以下顺序操作：

**新建或编辑能力 → 编写 SQL → 解析并确认字段 → 保存回能力组 → 整体试跑 → 核对并发布 → 用于分析**

## 一、第一次体验

在取数能力列表中找到“优惠券支付分析 · 完整示例”，点击卡片上的“配置指标与 SQL”“试跑”或“用于分析”，查看已有配置、数据和分析输入。

体验取数时可使用默认上下文：实验 ID `4823214`，观测时间 `2026-10-01` 至 `2026-10-03`，券模板 `101 / 102`。

## 二、从配置到分析

### 1. 新建或打开取数能力

点击“新建取数能力”，或在已有能力卡片上点击“配置指标与 SQL”。

填写能力名称和说明；业务目标固定为“平台老客提频”。Key 在首次保存时自动生成，之后只读展示，改名不改变 Key。

### 2. 编写 SQL，查看可用参数

在“指标”区域点击“新建 SQL”，编写 SQL；在编辑器下方填写指标组名称，说明可以按需展开。

点击编辑器右上角“可用参数”，浏览或搜索参数的名称、Key、类型与含义；点击参数即可在光标处插入占位符，例如 `${libra_id}`。具体参数值在试跑时填写。

一条完整 SQL 可以同时输出多个指标与维度。例如，同时计算 GMV、订单量，并按消费力和城市分组。

也可以点击“获取 SQL 模板”。用户粒度模板默认生成 User、订单量、人均订单数、订单渗透和下单用户数，便于体验指标配置；应用模板会替换当前 SQL 与指标配置。

### 3. 解析、绑定入参并配置指标

系统默认自动校验语法并解析字段，也可点击“校验并解析 SQL”或“重新校验与解析”。编辑阶段不取数；无法静态确定的类型需要人工确认。

解析按钮下方是“上下文入参绑定”。同名目录参数自动绑定，完整后可折叠；未知参数或类型不匹配时自动展开，请选择正确的上下文来源。这里只绑定来源，实验 ID、日期等实际值在试跑时填写。

在“指标组”表中修改指标名称、计算类型和表达式。支持 SQL 原值、SUM、AVG、UV、A / 进组用户数、A / B 和进组用户数，同一 SQL 字段可配置多条指标。例如，从 `order_cnt` 配置订单量、人均订单数和订单渗透。

点击“添加指标”新增一行，行右侧可复制、删除或上下移动。“更多设置”里配置 Key、口径、格式、精度、单位和空值显示。“自动配置指标”按 SQL 输出补齐未配置项，保留已有设置。

UV 统计字段大于零的去重实体数；人均与进组人数要求 SQL 覆盖全量进组用户并输出实体 ID。用户粒度模板保留零订单用户。

需要确认维度、原生类型或分组字段时，展开“SQL 输出与维度”。数字城市 ID 可以设为维度，`group_id`、`group_name`、`is_control` 保留为身份字段。若出现“需复核”，检查变化后点击“已核对字段变化”。

### 4. 保存回能力组，确认下钻

点击“保存并返回能力组”，SQL 会自动关联到当前能力。勾选本次需要的指标，并检查下钻分组。

| 使用方式 | 如何操作 |
| --- | --- |
| 完整 SQL 已输出指标和维度 | 维度自动带入；一个维度形成单维结果，多个维度形成交叉结果。 |
| 指标需要组合独立维度来源 | 点击“添加维度”，从“指标内置 / 公共维度 / 自定义 SQL”中选择，或点击“SQL 维度”新建；使用支持下钻的指标模板，确认实体 ID、维度值、类型和取值时点。 |

多选普通维度会分别生成独立卡、分别取数。“交叉维度”选择 2–4 个成员，单独联合取数。点击卡片“拆解”可从全部取值改为部分取值。完整 SQL 只提供自身已声明的粒度，其他粒度需要对应 SQL。

“展示不拆分维度的数据”控制整体结果是否展示；关闭前需保留维度拆分。修改这个开关不需要重新取数。

组合 Key 自动生成且只读，说明选填；在“更多设置”中可以查看绑定 SQL、切换各成员的引用版本，或复制成自定义 SQL 后编辑。已有拆解条件会随复制保留。指标内置维度需要保留其所属指标组。完成后点击“保存草稿”；系统在取数与发布时自动校验配置，存在缺项时按提示修正。

### 5. 整体试跑并核对

点击“整体试跑”，在打开的取数验证浮层中输入实验 ID 和观测起止时间，查看关联实验信息。其他入参在“更多上下文参数”中填写。

检查已选指标、维度和取数任务数，再点击“获取数据”。任务状态、错误提示和结果表均在浮层中呈现；完成后逐一查看实际 SQL 和字段口径。

确认无误后，勾选“已逐一核对全部结果、指标口径和下钻粒度”。出现空数据、执行失败或校验问题时，按页面提示修正后重新试跑。

点击“返回配置”、右上角关闭按钮或按 Esc 返回原页面。配置页只显示最近试跑状态，查看详细结果时重新打开浮层。

### 6. 发布取数能力

在取数验证页面点击“发布取数能力组”，或返回配置页点击“发布能力”，检查弹层信息并确认发布。

发布后生成固定版本，可在“发布记录”中查看。能力内 SQL 可以随能力组统一发布，无须先独立发布 SQL。

### 7. 用于分析

点击“进入分析模块”或“用于分析”，确认“能力版本”，选择需要分析的指标和结果分组。

填写“分析思路”和“注意事项”，在“试跑上下文”中确认实验与观测时间，再点击“分析试跑”。

查看“分析输出”，点击“查看数据证据”可定位到对应输入数据。能力发布新版本后，已有分析仍使用原版本；需要使用新版时手动切换“能力版本”。

## 三、修改与日常管理

- **修改后再发布**：SQL、查询配置或上下文改变后重新试跑；展示配置改变后重新核对。目录中的“vN+1 草稿待发布”表示当前修改尚未进入发布版本。
- **稳定 Key**：能力与 SQL 的 Key 由系统生成，只读展示；SQL 输出字段 Key 可在字段“更多”中修正。
- **查找能力**：按名称或 Key 搜索，并使用来源、状态筛选。
- **归档与恢复**：在卡片“更多操作”中归档并确认影响；通过“已归档”状态找到对象后恢复。已有固定版本引用保留。
- **使用内置 SQL**：可查看和试跑；需要修改时先“复制为自定义 SQL”。内置 RPC 不提供 SQL 编辑或复制。

## 四、需要跨能力复用同一 SQL 时

展开列表下方“SQL 复用管理”，点击“管理可复用 SQL”。

新建或打开独立 SQL → “进入取数验证” → 在同一浮层取数并核对 → “发布 SQL 取数项” → “关联取数能力组” → 加入已有组或新建组。

未独立发布的 SQL 只归属一个能力组；跨组复用使用已发布 SQL 版本。加入目标能力后，仍需整体试跑、核对并发布该能力。

## 当前演示环境

顶部“演示环境”可查看环境范围。取数使用示例底表，配置、记录和发布版本保存在当前浏览器，不自动跨浏览器同步。需要验证异常路径时，在该入口展开“测试设置”选择取数场景或发布失败；恢复正常使用前将取数场景切回“正常数据”并关闭发布失败。

# M-Sense 自定义 SQL 基本使用说明

适用对象：配置取数能力的 DS、分析师。对应 2026-10-22 更新的交互原型。

[打开取数能力列表](https://msense-sql.vercel.app/#/capabilities) · [打开页面内配置流程](https://msense-sql.vercel.app/#/guide)

通常按以下顺序操作：

**新建或编辑能力 → 编写 SQL → 解析并确认字段 → 保存回能力组 → 整体试跑 → 核对并发布 → 用于分析**

## 一、第一次体验

在取数能力列表中找到“优惠券支付分析 · 完整示例”，点击卡片上的“编辑”或“试跑”，查看已有配置与数据。分析输入在“实验分析模块”中选择。

体验取数时可使用默认上下文：实验 ID `4823214`，观测时间 `2026-10-01` 至 `2026-10-03`，券模板 `101 / 102`。

## 二、从配置到分析

### 1. 新建或打开取数能力

点击“新建取数能力”，或在自己创建的 SQL 能力卡片上点击“编辑”。内置 SQL 和自定义 SQL 均可查看、试跑；编辑仅对创建人开放。点击名称或“查看”打开只读配置，创建人可再进入编辑。

填写能力名称和说明；业务目标从目录页共用的下拉列表选择，目前只有“老客提频”，新建时默认选中。Key 在首次保存时自动生成，之后只读展示，改名不改变 Key。

### 2. 编写 SQL，查看可用参数

在“指标”区域点击“新建 SQL”。表单分为“指标”和“维度”两个大区块，各自的 SQL 配置器、解析操作和配置表都放在区块内部。先在指标区填写指标组名称、编写指标 SQL，说明可以按需展开。

点击编辑器右上角“可用参数”，浏览或搜索参数的名称、Key、类型与含义；点击参数即可在光标处插入占位符，例如 `${libra_id}`。具体参数值在试跑时填写。

完整 SQL 配置页的“可引用上下文”在编辑器上方按单列平铺，可搜索名称、Key 或说明。每行支持复制占位符或插入当前 SQL 光标／选区；解析后列表保持展开，搜索不改变 SQL。只读查看时可搜索和复制。

演示中，SQL 没有维度时会补充“消费力分层、生命周期、八大人群”三个 mock 维度，旧已解析示例也会自动补齐。可修改维度名称、Key、描述和拆分 SQL，并任选两个维度体验交叉组合。

一条完整 SQL 可以同时输出多个指标与维度。例如，同时计算 GMV、订单量，并按消费力和城市分组。

也可以点击“获取 SQL 模板”。用户粒度模板默认生成 User、订单量、人均订单数、订单渗透和下单用户数，便于体验指标配置；应用模板会替换当前 SQL 与指标配置。

### 3. 解析、绑定入参并配置指标

系统默认自动校验语法并解析字段，也可点击“校验并解析 SQL”或“重新校验与解析”。编辑阶段不取数；无法静态确定的类型需要人工确认。

解析按钮下方是“上下文入参绑定”。同名目录参数自动绑定，完整后可折叠；未知参数或类型不匹配时自动展开，请选择正确的上下文来源。这里只绑定来源，实验 ID、日期等实际值在试跑时填写。

在“指标”大区块内点击“一键解析配置指标”，解析当前 SQL 并补齐指标，已有人工设置保留。在表中修改指标名称、计算类型和表达式。支持 SQL 原值、SUM、AVG、UV、A / 进组用户数、A / B 和进组用户数，同一 SQL 字段可配置多条指标。例如，从 `order_cnt` 配置订单量、人均订单数和订单渗透。

点击“添加指标”新增一行，行右侧可复制、删除或上下移动。“更多设置”里配置 Key、口径、格式、精度、单位和空值显示。

UV 统计字段大于零的去重实体数；人均与进组人数要求 SQL 覆盖全量进组用户并输出实体 ID。用户粒度模板保留零订单用户。

“维度”大区块内点击“一键解析配置维度”，查看和修正当前 SQL 的维度名称与原生类型。也可选择实际 SQL 输出字段并点击“添加为维度”；数字城市 ID 可以设为维度。

可选下钻区提供“指标内置 / 公共维度 / 自定义 SQL”三类入口。需要独立编写维度 SQL 时，选择“自定义 SQL”，点击“新建 SQL 维度”，编辑器直接展开在维度大区块内。编写每个实体一行的 ID 和维度值，点击“一键解析配置维度”，选择需要的值列，确认维度名、Key、枚举及原生类型后点击“保存维度”。多个值列分别添加为独立维度，保存后自动关联当前能力，指标内容保留；取消编辑不会留下未完成的维度。

需要检查全部输出或分组字段时，在 SQL 配置区展开“SQL 输出字段”；`group_id`、`group_name`、`is_control` 保留为身份字段。若出现“需复核”，检查变化后点击“已核对字段变化”。

### 4. 保存回能力组，确认下钻

点击“保存并返回能力组”，SQL 会自动关联到当前能力。勾选本次需要的指标，并检查下钻分组。

| 使用方式 | 如何操作 |
| --- | --- |
| 完整 SQL 已输出指标和维度 | 维度自动带入；一个维度形成单维结果，多个维度形成交叉结果。 |
| 指标需要组合独立维度来源 | 在维度区选择“指标内置 / 公共维度 / 自定义 SQL”；自定义来源中点击“新建 SQL 维度”，在区块内编写并保存。使用支持下钻的指标模板，确认实体 ID、维度值、类型和取值时点。 |

多选普通维度会分别生成独立卡、分别取数。“交叉维度”每组选择 2–3 个成员，可新增多组，各组单独联合取数。自定义 SQL 单页中点击“新增交叉维度”，选择维度 A、B；需要三维叉乘时点击“添加第三个维度”并选择维度 C，再点击“生成组合 SQL”。各组可独立修改、删除；相同组合不能重复生成，未完成组可保存草稿，须完成或删除后才能试跑和发布。点击下钻卡片“拆解”可从全部取值改为部分取值。完整 SQL 只提供自身已声明的粒度，其他粒度需要对应 SQL。

“展示不拆分维度的数据”控制整体结果是否展示；关闭前需保留维度拆分。修改这个开关不需要重新取数。

组合 Key 自动生成且只读，说明选填；在“更多设置”中可以查看绑定 SQL、切换各成员的引用版本，或复制成自定义 SQL 后编辑。已有拆解条件会随复制保留。指标内置维度需要保留其所属指标组。完成后点击“保存草稿”；系统在取数与发布时自动校验配置，存在缺项时按提示修正。

### 5. 整体试跑并核对

点击“整体试跑”，在打开的取数验证浮层中输入实验 ID 和观测起止时间，查看关联实验信息。其他入参在“更多上下文参数”中填写。

检查已选指标、维度和取数任务数，再点击“获取数据”。任务状态、错误提示和结果表均在浮层中呈现；完成后逐一查看实际 SQL 和字段口径。

点击“试跑”默认先展示输入信息，即使之前取过数据也不会直接显示旧结果。点击“获取数据”后才显示本次任务与结果；修改入参后结果收起，重新获取后显示新结果。

创建人可通过浮层右上角的“历史试跑记录”按实验、时间和状态查看之前的取数；有记录时才显示入口。历史详情展示当次只读入参与结果，不提供取数、核对或发布；“返回当前验证”保留本次填写的信息。能力目录的更多操作也提供历史入口，配置页“试跑记录 · N 次”首次有记录后出现，默认收起。其他人只查看本次试跑结果。一轮取数只计一次，多个下钻任务属于同一记录。

确认无误后，勾选“已逐一核对全部结果、指标口径和下钻粒度”。出现空数据、执行失败或校验问题时，按页面提示修正后重新试跑。

点击“返回配置”、右上角关闭按钮或按 Esc 返回原页面。配置页只显示最近试跑状态，查看详细结果时重新打开浮层。

### 6. 发布取数能力

在取数验证页面点击“发布取数能力组”，或返回配置页点击“发布能力”，检查弹层信息并确认发布。

发布后生成固定版本，创建人可在“发布记录”或目录更多操作的“历史版本”中查看。能力内 SQL 可以随能力组统一发布，无须先独立发布 SQL。

### 7. 用于分析

点击“进入分析模块”或“用于分析”，确认“能力版本”，选择需要分析的指标和结果分组。

填写“分析思路”和“注意事项”，在“试跑上下文”中确认实验与观测时间，再点击“分析试跑”。

查看“分析输出”，点击“查看数据证据”可定位到对应输入数据。能力发布新版本后，已有分析仍使用原版本；需要使用新版时手动切换“能力版本”。

## 三、修改与日常管理

- **修改后再发布**：SQL、查询配置或上下文改变后重新试跑；展示配置改变后重新核对。目录中的“vN+1 草稿待发布”表示当前修改尚未进入发布版本。
- **稳定 Key**：能力与 SQL 的 Key 由系统生成，只读展示；SQL 输出字段 Key 可在字段“更多”中修正。
- **查找能力**：按名称或 Key 搜索，并使用来源、状态筛选。
- **使用内置 SQL**：支持查看和试跑；创建人还可编辑、查看历史版本与试跑记录。创建人权限与来源标签分别判断。
- **目录操作**：配置完成后出现“试跑”；配置未完成但有历史时显示“查看验证”。目录不再提供“用于分析”按钮。
- **历史入口**：仅创建人可用；有版本显示“历史版本”，有运行显示“历史试跑记录”，两项都没有时隐藏更多操作。
- **内置 RPC 试跑**：仅支持查看和试跑。点击“查看”，勾选至少一个指标后试跑立即启用；取消全部勾选后恢复置灰。标题中的“提供 N 个指标”是平台能力范围，勾选数在明细中展示。

## 四、载入已有取数能力

新建或打开可编辑能力，在页头点击原“保存草稿”紧邻左侧的“载入已有取数能力”。选择弹层支持按能力名称或 Key 搜索，并显示名称、说明及使用的版本。

来源有发布版本时使用最新已发布快照，不使用其未发布修改；没有发布版本时使用已保存草稿。当前对象、未保存及没有完整可读取定义的能力不列入选择；固定样例 RPC 不会自动转为 SQL。

当前已有指标、SQL 或维度内容时，确认一次后整体替换；空能力直接载入。取消、关闭或载入失败不会修改当前取数内容。当前能力的 ID、Key、名称、说明、业务目标、实验上下文、发布版本和历史记录保留，不承接来源试跑及核对状态，也不自动执行 SQL。

载入的自定义 SQL 成为当前能力内草稿，修改不影响来源能力；内置 SQL 保留固定引用和只读约束。随后点击原“保存草稿”，继续按现有流程试跑、核对和发布。首次保存时才生成新能力和新 SQL 的稳定 Key。

## 当前演示环境

顶部“演示环境”可查看环境范围。取数使用示例底表，配置、记录和发布版本保存在当前浏览器，不自动跨浏览器同步。需要验证异常路径时，在该入口展开“测试设置”选择取数场景或发布失败；恢复正常使用前将取数场景切回“正常数据”并关闭发布失败。

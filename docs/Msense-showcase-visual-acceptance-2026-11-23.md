## 第一轮问题 V01（第二轮已修复）

**分类：优化类。位置：报告目录 → 章节跳转。**

复现步骤：

1. 在桌面视口打开 Showcase。
2. 点击左侧目录「03 电商人群贡献」。
3. 等待滚动停止，查看页面顶部的章节标题及报告工具栏。

实际表现：章节标题被顶部区域遮住，首个可见内容是副标题或分析结论；目录的首项及报告工具栏也可能离开可视区域。浏览器观察到章节顶边约为 20 CSS 像素，外层页面同时产生滚动，未保持章节标题位于顶部界面下方。

预期表现：目录只滚动报告阅读区域，跳转完成后完整显示目标章节标题，并保留顶部导航/工具栏。图表和引用定位也应遵循同一可见范围。

当时影响：用户仍可阅读结论和数据，但章节定位不完整。第二轮以报告内部容器滚动替换外层 `scrollIntoView`，模块目录定位已在浏览器重测；引用、全屏、焦点与滚动状态通过更新后的 DOM 检查。真实手机及本轮窄屏实测仍未完成。
